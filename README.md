# 人话 · renhua

中文 | [English](README.en.md)

把中文稿中空泛、僵硬、重复和不合语境的表达改自然，保留事实、判断、语气与作者声音。

它是表达编辑 skill，不是 AI 来源检测器。不会为了“像人”强加口语、短句、网络梗或文学腔，也不承诺降低检测分数。

## 怎么用

把稿件交给支持 Agent Skills 的工具，例如：

```text
用 renhua 把这段改自然，保留我的口吻，只给改稿。
这是写给客户的邮件，去掉模板腔，不要把商量改成催促。
整理这份技术说明的措辞，代码、参数和步骤编号不要动。
```

默认只输出完整改稿。想看修改理由可以说“附关键改动说明”；原稿已经自然时可以不改，不用为了凑改动交一张台帐。

不用声明原稿是哪家模型生成的。用途、读者或风格样本已经明确时按它们处理；没有时沿用原稿，不自行搜索私人文件或建立作者画像。

## 它会改什么

- 删掉没有实际作用的重复解释、预告与自我评价。
- 用贴切措辞和词序修复僵硬表达，必要时拆合句。
- 理清原有的指代与衔接，不把并列改成因果。
- 收敛遮住内容的修辞与重复强调，保留有作用的比喻、排比、问句和停顿。

**能改语言形式，不代表能改意思。** 数字、术语、引语、来源、限定、立场、责任和请求力度都需要保留。没有新事实的句子也可能有用：它可能在回应担忧、交还决定权或形成节奏。

### 一组构造示例

原文：

> 小组完成了对值班安排的调整。如果方便，请周三前告诉我；来不及也请说一声。

可以改为：

> 小组调整了值班安排。如果方便，请周三前告诉我；来不及也请说一声。

前一句可以简化，后一句的宽限不是赘词，不能改成“请于周三前提交”。这是说明编辑边界的例子，不是效果统计。

## 默认范围

| 可做 | 不自动做 |
|---|---|
| 保义换词、调整语法、词序与句子断合 | 补事实、数据、经历、动机或新观点 |
| 修改普通说明段落，不因文件叫README就停用 | 改代码、参数、原话、义务、条件或来源 |
| 收敛无功能的重复加粗 | 改章节层级、步骤编号、表格或交叉引用 |
| 识别组织问题，给简短建议 | 重排、拆合正文段落，或改变论证、叙事揭示顺序 |

需要结构重构时明确说即可，仍只使用原有材料。要求“仅改错字”“只审不改”或“保持格式”时，不扩展成全面润色。

中英文混合稿只处理授权范围内的中文表达；纯英文不套中文建议。简繁、地域词、人称和原稿已有的声音保持一致。

## 安装与更新

复制整个 skill 目录，而不是只复制主文件：

```bash
git clone https://github.com/RiAnBee/renhua.git
mkdir -p ~/.claude/skills
cp -r renhua/skills/renhua ~/.claude/skills/
```

也可以复制到你的工具支持的 skills 目录。**已有旧安装时，先移走旧的 `renhua` 目录，再复制新目录**，避免覆盖合并留下旧规则。若使用指向仓库的软链接，仓库内容更新会直接生效。

仓库保留插件入口；支持本地插件目录的 OMP 可使用：

```bash
omp --plugin-dir ./renhua
```

命令入口位于 `commands/renhua.md`，只路由到核心，不维护第二套规则。未配置插件市场，因此这里不提供未经验证的 marketplace 安装命令。

## 为什么不再“只做减法”

旧版把不增加事实扩大成了不允许正常替换，并用句长、人机频率与规则命中数约束编辑。本次撤销这些处方：**能区分来源，不等于改掉后文章更好。**

[LAMP](https://arxiv.org/abs/2409.14509v5) 的职业编辑包含大量替换，不支持“只删不换”；[StoryScope](https://arxiv.org/abs/2604.03136v6) 研究的是叙事区分信号，不能用其分类结果证明结构编辑无益。中文问答、新闻翻译与语体研究也不能合成唯一的句长标准。

完整依据与适用边界见证据摘要。旧研究保留供复核，不再把“未复现”写成“永远不能改”，也不把历史小样本比例称为当前误删率真值。

## 验证与局限

检查改稿时，先问“有没有改动含义、语气或承诺”，再问“是否更适合这次用途”。不要用改动数量、人机来源或检测器分数代替这两个问题。

本轮开发材料为36篇原创合成稿，另封存120篇不同主题的合成确认稿。它们用于工程验证，**不是人类语料基线，也不是世界最好或真实世界安全性的证明**。直接提示运行、真实skill加载、模型辅助审查和真人盲评的完成情况分开记录在执行报告中。

运行仍依赖编辑模型的判断，无法形式化保证信息不变。强风格、法律与专业内容应由作者或相关使用者复核；缺材料时只能指出缺口，不能靠改写找回原稿没有的事实与判断。候选是否稳定优于简单编辑提示，需要完整文档对比和中文读者评审。
