用户追问依据时读这个文件。**不要把本文件内容塞进正文回答**，只在被问到细节时引用。

## 0. 自建中文语料（本项目自己的实测）

**这是本项目第一次拥有「原生中文人类基线」。** 此前唯一的中文证据来自英译中场景（自承源语干扰）。

| 层 | 来源 | 篇数 | 汉字 |
|---|---|---|---|
| 人类·正式 | 人民网 | 100 | 174,040 |
| 人类·口语 | 博客园个人技术博客 | 82 | 179,425 |
| AI·正式 | 同一模型 × 40 个新闻话题 | 40 | 33,490 |
| AI·口语 | 同一模型 × 40 个技术博客话题 | 40 | 26,504 |

方法：逐篇特征值 → Mann-Whitney U（含并列修正）→ Cliff's delta。
**不用归一化均值比较**（会被长文主导）。脚本见 `scripts/{collect_corpus,analyze_corpus,stats_corpus}.py`。

**局限（随结论一起说）**：AI 侧只有一个模型族；人类侧网页文本未做 AI 污染净化；
「口语」层实为技术博客；特征均为正则可复现的表层量，无句法骨架标注。

### 稳健特征（两语域同向，p<0.01）

| 特征 | 正式 δ | 口语 δ | 与论文对照 |
|---|---|---|---|
| 平均句长 | −0.44 | −0.79 | ✅ 复现 2506.22050（且本次是原生中文基线） |
| **句长 CV** | −0.46 | −0.62 | ✅ 复现 2502.11266 方差收缩 |
| **段末句长 CV** | −0.53 | −0.30 | 🆕 自测发现，支撑 A5「节奏均匀」 |
| 跳步 CV | −0.61 | −0.31 | ✅ 复现 2605.27878 |
| 跳步均值 | +0.40 | +0.33 | ✅ 复现 2605.27878（差异全在 SD、均值 AI 略大） |
| 问句 | −0.33 | −0.25 | ✅ 复现「正文问句人类 17×」 |

跳步均值与跳步 CV 这一对**完全复现** 2605.27878 的结论，是对本项目分析管线的独立交叉验证。

### 语域依赖（方向相反）—— 混池会骗人的直接证据

| 特征 | 正式 | 口语 | 混池（错误做法） |
|---|---|---|---|
| **转折连词** | **6.47×**（δ=+0.49） | **0.13×**（δ=−0.25） | 2.15× |
| 模糊归因 | 13.10×（δ=+0.53***） | 无差异 | 10.64× |
| 让步转折公式 | 人类 0 / AI 0.184 每千字（δ=+0.17***） | 0 | — |
| 破折号 | 2.35×（δ=+0.21*） | 无差异 | 1.62× |
| 比喻标记 | 无差异 | −0.35***（AI 少） | −0.41 |
| 序数结构词 | 无差异 | 1.90×（δ=+0.35**） | 1.50× |
| 元文本导航 | 无差异 | δ=−0.30**（AI 少） | — |
| 反向对举 | 无差异 | 5.36×（δ=+0.19*） | 5.24× |

**转折连词一项足以说明混池的代价**：混池给出 2.15×，而真实是 6.47× 与 0.13×，两个语域都不成立。

### 未复现（诚实记录）

对举（不是…而是）、段首框架句、空转冒号引列表、结论套话 —— 本语料上**无显著差异**。
原因：生成 AI 语料时要求"写成文章"，模型很少写列表，该形态**没有机会出现**。
这是语料设计的盲区，不是对参考基线的反驳。

### 根因实验（AI 味来自「助手人格」吗？）

**假说被否证。**

姿态框定实验（12 话题 × 4 框定）：起手式出现率 A 助手 0.167 / B 作者 0.250 /
C 私人通信 0.250 / D 助手带受众 0.167 —— **姿态不改变起手式**。
但姿态**确实改变**第一人称（1.77→9.98，5.6×）与序数词（0.75→3.25），说明框定有效，只是不作用于起手式。

文体框定实验（12 话题 × 2 文体 + 探索）：**原则陈述 7/17 = 41%**，技术说明 2/17 = 12%，
定位宣言与操作指南 0/5。

→ **起手式的触发是「文体」，不是「姿态」**。且 41% 是高频形态而非必然标志。

### 已知方法论教训

**引用数字前必须读表头与 caption。** 本项目曾把 `2507.12260` 表格的
「low / high-translationese translations」两列误读为「人类 vs AI」，
据此得出的"中英代词方向相反"结论不成立（两列都是机翻译文）。
详见 `CONTRIBUTING.md`。

## 五、中文侧证据的真实状况（诚实声明）

| 事实 | 说明 |
|---|---|
| **干净的中文原生人机对照几乎不存在** | 唯一有原生中文人类基线的是 arXiv:2506.22050，但它是**英译中翻译场景**，自承源语干扰；arXiv:2603.14430 只有结构层；arXiv:2507.12260 两侧都是译文 |
| **一个被误读的数字（勿再引用）** | arXiv:2507.12260 `benchmark-dataset-stat.tex` 的表头是 `low \| high`，caption 明写 *low- and high-translationese translations* —— **两列都是机翻译文**，测的是源语干扰强度，不是人机差异 |
| **中文句法现象级证据 = 0 篇** | 前置过长定语、「当…时」、「对于…来说」、句首连接词、「这意味着」在学术文献里**对中文零证据**；参考基线自测 2.6–5.3×（实践观察级） |
| **中外产 LLM 不可区分** | 66.63% ACC，F1 0.519（arXiv:2506.22050） |
| **模型间可归因度远低于人机** | 六路归因 68.4% vs 人机 93.2%；五个模型簇成一团（StoryScope） |

### 参考基线（`lieflat-less-ai-tone`，中文）

语料：AI 300 篇 × 1,179,105 汉字（5 模型各 60 篇，38 个话题）／人类 329 篇 × 1,647,867 汉字。
方法：对照实验，倍率 = AI 频率 ÷ 人类频率，≥2.0 收录，且要求人类侧组间稳定。

**该基线自己的"测不出来"清单**（本 skill 据此排除）：句长变异 0.87×、
段落长度 0.94×、单字虚词 0.45×、口语连接词 0.26×、被动句无差异、
动词名词化 0.52×、正文问句 0.05×、比喻 0.42×、句内排比 0.61×。

## 六、验收的数学上限（为什么不能用检测器分数）

| 结论 | 出处 |
|---|---|
| `TPR ≤ FPR + TV` —— 分布重叠 11% 时，"FPR<0.01 且 TPR>0.9"在数学上不可达 | arXiv:2303.11156（TMLR）Corollary 3 |
| 检测器判定率与 AI 参与度**不单调**：12 个检测器里 **6 个**在重度改写上反而判得更少 | arXiv:2502.15666 |
| 人类（非专家）判断接近随机 | 0.499（arXiv:2601.07368）；非专家 TPR 56.7% / FPR 51.7%（arXiv:2501.15654） |
| 老练读者可近完美 | 5 人多数投票 TPR **99.3** / FPR **0**；重度 LLM 使用者约 90%（arXiv:2501.15654） |

→ **本 skill 服务的是老练读者，不是检测器。**

| 项 | 说明 |

## 八、本项目未采用的机制（记录以免重复调研）

| 机制 | 为什么不用 |
|---|---|
| 解码期分布相减（CoPA） | 需改解码层，不是写作规则（arXiv:2505.15337，效果实测很强） |
| 风格 SFT + DPO + 推理期精修（MASH） | 需训练（arXiv:2601.08564，ASR 92%） |
| 逐字复用人类原文（Frankentext） | 需大规模人类语料 + 未公开作品，有版权问题（arXiv:2505.18128） |
| 递归复述多轮 | 破坏连贯性（人工连贯降到 71%），且 JSD 远超人类编辑幅度（arXiv:2303.11156） |
| 针对检测器重优化提示 | 需检测器 API + 自动化循环，且不解决"像人写"（arXiv:2606.25152） |

**这些不是本 skill 的目标。** 本 skill 的目标是让老练读者觉得文字是人在说话。
