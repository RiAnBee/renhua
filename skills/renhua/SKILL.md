# 人话

改的不是一批“像 AI 的词”，而是稿子里那些表面完整、却没有落到这次具体沟通的表达。先弄清这句话在替谁、对谁、为哪件事承担什么，再决定是否动字。

自然不等于口语、短句或文学腔。公文可以像公文，技术说明可以保留术语，作者也可以保留自己的停顿、重复和判断力度。

## 先恢复情境化承诺

读完整个待改范围，再在内部回答：

- 为什么现在要说这件事？
- 这句话具体指向谁、什么、哪份材料或哪段经历？
- 作者到底声称了什么，依据和把握到哪一级？
- 它和前后句是什么关系：并列、因果、让步、条件、时间还是解释？
- 读者读完要能判断什么、做什么，或暂时不判断什么？
- 说错谁承担什么后果？
- 哪些顺序、停顿、重复或词语已经形成作者的声音？

这些问题是判断依据，不要机械写进正文。缺项标为未知；未知不能自动变成删改理由。材料没有提供的事实、经历、动机和来源，不替作者补。

## 逐句检查，不先列禁词

对每个可疑表达问：

1. 它让读者多知道了什么、能判断什么或需要做什么？
2. 它具体对哪个对象、命题、关系、条件、后果或作者选择负责？
3. 如果删掉或换掉，读者会丢失什么？
4. 把它换成一个近义但不同结构的说法，问题仍在不在？

只有在同一表达可以套到几乎任何主题和作者、没有承诺对象、也不承担礼貌、立场、范围、转折、总结、节奏或体裁功能时，才把它列为泛化候选。无法证明就留在待查，不改。

“满”“很满”“一律”“而”“不是……而是……”、标题、总结和抽象名词都不是禁用项。`这话他跟甲方说得太满，当场就被砍了两条`里的“满”有施事、受话人和后果；不能因词形相同就删。段首和段末只是优先取样位置，不是规则边界。

## 按缺口编辑

按这个顺序处理：

1. **命题和对象**：已有材料能回接就回接；没有材料只指出缺口。
2. **关系**：修正分句顺序、断合和连接方式；不能把并列改成因果，把后知改成先知。
3. **承诺**：保住或恢复来源、否定、条件、例外、责任和把握程度。
4. **读者状态**：删掉读者已经知道的重复，或补回完成任务所需的前提。
5. **形式负担**：最后才调词序、句法、标点和节奏。

不要把“说明这段文字”自动当作错误。有些元话语在目录、操作说明、学术论证和交接文档中有用；先问它是否完成当前读者需要的动作。

## 保住含义，也保住声音

- 保留实体、数字、单位、术语、引语、来源、时间、因果、否定、条件、例外和不确定性。
- 保留责任、承诺、请求力度、礼貌、强调、幽默、反讽、有意停顿以及作者已有的词语偏好。
- 不把含糊改成确定，不把推测改成结论，不把转述改成逐字引语。
- 不为追求具体、顺滑或“像人”而新增事实、动机、责任、结论、标题、口吻或作者身份。
- “不承担功能”不等于“应该改”；若删改损失说得出的读者动作，保留。

语言可以换，信息和作用不能随便换：

> “建议延期”不等于“需要延期”；“仍可使用”不等于“完全不受影响”。

碎句、重复、排比、正式措辞、连接词和比喻都不自动构成问题。公文、法律、专业文本和强风格文本尤其要按用途复核。

## 编辑范围与权限

用户说“去AI味”，授权在不改变内容和语用的前提下处理空转、结构错位、关系误导、重复填充和体裁内部的过度整齐；不是授权换成统一口吻。

允许：保义换词，调词序和语法，必要时拆合句，删除没有功能的重复，修复指代和关系。

不自动做：补事实、数据、经历、动机、观点或来源；动代码、参数、原话、义务、条件或引用；改章节层级、编号、表格、交叉引用；重排段落、论证或叙事顺序。

用户说“只改错字”“只审不改”或“保持格式”，就只做那个范围。要求结构重构时，仍只使用已有材料。

混合文本只动获授权的中文部分；纯英文不套中文编辑建议。简繁、地域词、人称和正式程度跟原稿走。提供了风格样本时参考其选择，不复制其中事实、经历或口头禅。

## 交付与验收

默认只交完整改稿。原稿已经自然，就原样返回，不凑改动；用户要理由时再附关键改动。

交稿前做两次核对：

1. **保留检查**：实体、数字、来源、否定辖域、关系方向、承诺强度、礼貌力度、责任和声音是否还在。
2. **新增检查**：是否因为“更自然”而加入原文没有的事实、动机、责任、结论或作者姿态。

用途明确时，用目标读者任务复核：能否找到决定、复述条件、判断是否执行、指出证据或确认谁负责。没有中文完整读者评测，不承诺“改完更像人”，也不输出检测分数。

需要依据时读 [evidence.md](references/evidence.md)；需要情境边界时读 [situating.md](references/situating.md)；觉得某处怪但说不出原因时读 [ai-flavor-cases.md](references/ai-flavor-cases.md)。这些文件提供例证，不把词、位置或统计量变成禁令。
