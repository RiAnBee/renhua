# 方法论压力测试：五步流程与案例复核

日期：2026-10-25

## 结论先行

把五步法实际套到五份文本后，最稳定的产出不是“像不像人”，而是两类很窄的判断：文本内部是否自洽，以及面向一个已知任务时是否缺少执行所需的材料。它对公文和 README 的“缺什么”比较敏感；对随笔的节奏、声音、陈套表达和作者归属几乎不能给出可复核的判定。

五份中，**至少 4/5（80%）的情境卡有一项以上关键维度无法由文本确定**（作者身份、真实读者、后果、材料来源或版本条件）；**3/5（60%）的最终风格/形式处置必须以文本外信息为前提**。若把“功能是否必要”也要求达到两位合格读者可重复的标准，则 5/5 都存在未决点。因而“无法判断”并非边角输出，而是该程序的常态；它只有在把“可判”收窄为“可执行字段/内部逻辑”时才可证伪。

## 每个案例的过程记录与未决点

### 1. 人类 S3 公文

- **情境卡的推断边界**：可从“经国务院同意”“党的二十大”推断制度语境，但不能从片段推出正式署名、文号、发布日或附件。把“作者=国务院”写成确定值会把发文机关、审议机关和政策来源混为一谈。
- **功能归因的竞争解释**： “坚持以人民为中心”“促进高质量充分就业”既可能是必要的政策立场，也可能是可删的套语。流程只有“承担功能/不承担且冲突/不承担但不冲突”，没有给出“功能证据”的可重复标准；两位读者可一位保留、一位以压缩为目标删除，且都能援引目的“政策部署”。
- **缺口依赖完整文件**：片段没有指标、财政来源、责任单位，但它可能只是意见的开头，不能据此判定全篇缺口。因而“文本片段”与“完整文书”的单位未规定。
- **效果验证不可做**：没有指定执行者和任务，无法进行“找到某个决定/复述条件/判断要不要照做”的读者任务。

### 2. AI S3 公文

- **“不可用”标准未定义**：通知可以是面向下级的原则性动员，也可以是现场指挥单；前者不一定需要水位阈值和逐人名单。流程没有规定何种公文类型的最低字段集合。
- **“适时/及时”是缺口还是体例**：在应急文书中它们可能故意保留裁量；在执行通知中又可能构成后果缺口。需要部门规范、发布日期和附件，不是文本内部即可决定。
- **作者维度被过度重建**：末句“市政府办公室将适时开展督导检查”只能证明预设主体，不证明真实作者。方法要求“谁写、以什么身份承担责任”，但没有处理拟稿人、发文机关、署名机关三者分离。
- **基线与方法同向**：两者都能发现可执行字段缺失；五步法没有证明它能更准确地决定补什么，只能要求“补材料而不编造”。

### 3. 人类 S5 随笔

- **网页提示是文本还是载体噪声**：第 2 步会把它列为形式异常；第 3 步若把“读者会丢失什么”用于整篇，则可能误删真实的网页外壳。只有知道采集方式才能决定。
- **“克制/不渲染”的归因不可证伪**：正文中大量“白沙、沙海、苍凉、碧水”也可被读成渲染；“无连接词”可能是自然叙事，也可能是编辑缺漏。功能归因没有操作性编码或读者证据。
- **景物事实与审美评价没有分界规则**：白沙湖“地下水源维系”“不干不涸”需要外部材料，但方法只说“缺材料处不得要求具体性”，没有说明何时应查证、何时应把它当文学叙述。

### 4. AI S5 随笔

- **作者来源不能自动成为情境信息**：知道文件来自 `gpt-6.1-sol-v2-short` 只知道生成工具，不知道委托目的、编辑过程、署名和作者声音。方法禁止“模型爱这么写”，但没有提供无作者信息时的归属判定。
- **抽象收束的双重功能**： “丢弃它们并不代表否定过去”可以是对读者的安慰，也可以是生成文本的通用 moral；“生活已经走到了新的地方”可以是必要收束，也可以是空泛总结。三问无法在没有读者反应时排除任一解释。
- **换一个目的就换结论**：作为私人随笔，“补流程”破坏体裁；作为搬家指南，“暂时决定”没有操作定义。文本本身不能选择两个目的中的哪一个。

### 5. Apache APISIX README

- **多重读者使功能归因不唯一**：同一句“支持 ARM64”对选型者是兼容性信息，对营销读者是能力声称，对维护者是社区承诺；流程要求“读者是谁”，却没有多受众的优先级和冲突处理。
- **性能数字的情境重建不足**：18k 与 140k 并不必然矛盾，可能分别对应单核/八核、不同脚本和不同版本；也可能是 README 未更新留下的冲突。必须访问 benchmark 脚本、版本和硬件，单凭文本不能归因。
- **限制条件的强度没有阈值**：README 的目标是引导到安装指南，不是替代性能报告。方法没有定义“读者任务”达到什么程度才算缺口，也没有定义一个 README 必须披露哪些安全、版本和性能字段。
- **功能分类与模板化的关系**：长列表可服务检索，也可只是模板复制。第 3 步允许两种归因，但不规定证据优先级。

## 未充分规定之处（引文—问题—后果）

1. **“任何一项为‘未知’的维度，都不能成为修改理由”**（`methodology.md` §1，第 43 行）。这条保护了作者声音，却也阻止了对无署名文本中明显的读者风险作必要修改。五例中 S5 AI 的“作为指南还是随笔”因此无法分流；S3 片段也无法判断应否补正式发文要素。
2. **“这个动作在当前情境里是必要的吗？”**（§2，第 56 行）。必要性的标准没有操作化：法律/公文可以按规范字段核对，随笔和 README 的“必要”只能靠读者偏好或后果假设。5/5 至少有一处形式可由两种功能解释。
3. **“无法判断｜进待查，不修改”**（§2，第 65 行）。待查的外部材料清单、查询时限、何时可从待查转为判定没有定义。若所有涉及语体、声音、真实性和审美的项目都进待查，方法会对最需要编辑判断的部分失去作用。
4. **“任何一项为‘未知’的维度，都不能成为修改理由”**与“只查三处缺口”之间有张力（§1 第 43 行；§2 第 69–75 行）。读者未知时不能判“难懂”，但仍可判“读者缺口”；五例中没有规则说明何时这两个判断冲突。
5. **“读者任务：给目标读者一个具体任务……看是否达成”**（§2，第 80 行）。目标读者、任务和成功阈值都由评估者指定，存在反向设定任务使任何文本产生缺口的风险。APISIX 可被设为“快速选型”“安全部署”或“查找某插件”，三个任务得到不同 verdict。
6. **“保义五轴”**（§2，第 79 行）适合事实改写，不足以覆盖汉语韵律、篇章管界、指称可及性、语体合法性、元话语和作者归属。S5 两文形式上的差异恰在节奏、比喻和收束，五轴核对通过也不代表读者体验或声音被保留。
7. **“按层收集……句长、嵌套、省略……正式度、评价词……”**（§2，第 47 行）只列观察维度，没有规定抽样单位、边界、编码者一致性或“可疑”的阈值。APISIX 的 Markdown 列表、链接和代码混在同一清单时，形式层如何分段未定义。
8. **“缺材料处不得要求具体性”**（§1 第 41 行）保护了不编造事实的原则，却不能区分文学中的有意留白、新闻中的证据缺失和 README 中的决策风险。S5 人类的地下水描述与 APISIX 的性能条件因此需要完全不同的外部证据制度，但方法没有分支。

## 可证伪性判断

方法不是完全不可证伪：对一个明确任务、明确体裁和可核验材料集，它作出可检验预测。例如，给 AI S3 文本补入发文机关、适用地域、责任单位、报告时限和触发条件后，流程应不再把“指涉/后果缺口”判为阻断性缺陷；给 APISIX 性能数字补入硬件、版本和脚本后，读者任务中的可比性应提高。

但其目前的**总体风格判断**接近不可证伪。五例中：

- 0/5 能在文本内部独立完成六项情境卡；
- 4/5（80%）有至少一项会改变处置的外部未知；
- 3/5（60%）的关键结论只能写成“若目的/读者是 X，则……；若是 Y，则……”；
- 5/5 存在“承担功能”与“不承担但不冲突”之间的竞争归因；
- 只有 2/5（AI S3、APISIX）能在相对明确的任务下给出可操作的补充项，且补充项是否“必需”仍需体裁规范或外部材料。

因此，“无法判断”若只表示“不凭空改写”，是诚实的保守输出；若它被算作方法成功而不规定待查证据、裁决阈值和编码一致性，则方法可对任意结果免疫，成为不可反驳的编辑哲学，而不是判定法。

## 与朴素基线的比较

基线定义为：**只修内部不一致和明确缺失的必需元素；除此之外留原文。**

五例中有 4 例（人类 S3、人类 S5、AI S3、AI S5）基线和五步法的实际动作相同或近似相同：保留可解释的形式，补公文硬字段，删除明显的网页载体错位，不对随笔的节奏和抽象收束动刀。五步法提供了功能归因、保义检查和“不要编材料”的理由，但没有显示出更高的处置准确率。

APISIX 是一个可分叉点：五步法因后果缺口要求补性能条件、版本、失败边界和安全前置；严格基线若把 README 未列出这些看作非必需字段，则会保留原文。因此五步法**最多在 1/5（20%）案例中产生不同的建议**。但这不是稳定优势：一旦把“高后果 README 的性能条件”定义为明确必需元素，基线也会给出同一建议。当前材料不能证明五步法比基线更会决定“哪些缺失是必需的”。

## 对方法的最小修订建议（不改理论正文）

把五步法的产出从单一的“改/不改”改成三层：**（a）文本内部可核验结论；（b）依赖指定外部证据的条件结论；（c）不可裁决的风格/归属判断**。为每一层规定最小证据：公文用体裁规范和完整文书，README 用版本/环境/性能脚本及目标任务，随笔用作者/发表载体和读者反应。对“功能归因”至少记录竞争解释及其排除依据；对“无法判断”必须给出待查材料、查询动作和升级阈值。这样，情境卡不再是可以任意填充的总开关，五步法也不会把已有的“内部一致性 + 必需字段”基线包装成普遍的语言学判定。
