# 方法论：情境—功能—形式判定法

日期：2026-10-25（晚经压力测试修订，见 [review-method.md](review-method.md)）
配套理论：[human-expression.md](human-expression.md)　｜　验证记录：[verification-log.md](verification-log.md)

> **修订摘要（必读）**：五份真实文本的实跑显示，五步法与"修掉内部不一致和缺失要素"的朴素规则在
> **4/5 案例上给出相同动作**，唯一可能不同的是"后果缺口"。因此本版做三处收缩：
> ① 判定主线收敛为**三处缺口**（指涉/读者/后果）；② 功能归因**降级为否决权**，不再当修改理由；
> ③ 明确写出**能力边界**与"待查"的升级规则。风格、声音、节奏不在本方法能力范围内。

---

## 0. 这套方法要解决什么

不是"检测 AI"，也不跟任何模型比指纹。要解决的是：

> 给定一段中文，判断**某个形式选择是否应该改**；判断必须能在看不到模型的情况下完成，
> 并且在换模型、换版本、换风格之后依然成立。

结论先给：判据只能是**形式能否追溯到情境与功能**。凡是锚在"模型常用什么"上的判据，
都会随模型迭代失效——这一点已被本库的数据和文献同时证实（见 §6）。

---

## 1. 四条原则

| 原则 | 含义 | 反面做法（本库已否证） |
|---|---|---|
| P1 情境先于文本 | 先确定谁对谁、为什么、什么后果，再看形式 | 打开文本就找"AI 词" |
| P2 功能先于形态 | 同一形态在不同情境功能相反，不能按形态判冗余 | 禁用词表；重复即冗余 |
| P3 具体性看来源 | 指涉要靠真实材料供给；无材料处应标缺，不该编 | 要求"多写数字" |
| P4 判断要能失效 | 每个判断都写出它会错的条件 | 只给结论不给反例 |

---

## 2. 五步流程

### 第 1 步：情境重建（缺失项要显式标出）

| 维度 | 要回答什么 | 缺失时怎么办 |
|---|---|---|
| 作者 | 谁写、以什么身份写、承担什么责任 | 标"未知作者"，不推断 |
| 读者 | 谁读、已知什么、会据此做什么 | 标"读者不明"，此时不得判定"啰嗦/难懂" |
| 目的 | 告知／说服／请求／免责／记录／自证 | 多目的时分别列出，分别判 |
| 媒介 | 纸面、屏幕、口头、即时通讯 | 决定句长与标点的可用范围 |
| 后果 | 错了会怎样、谁承担 | 无后果的场合，宽容度应更高 |
| 材料 | 手上有什么真实数据、文件、经验 | **缺材料处不得要求具体性** |

产出：一张六项情境卡。任何一项为"未知"的维度，都不能成为修改理由。

### 第 2 步：形式清单（只列可疑项，不做全量打分）

按层收集：指涉（数字、时间、专名、引文）、句法（句长、嵌套、省略、被动）、
词汇（正式度、评价词、虚词）、标点、篇章（段落长度、连接方式、话题推进）。

### 第 3 步：功能归因（核心）

对每个可疑形式问三句：

1. 它在这里承担什么交际动作？
2. 若删掉/改掉，读者会丢失什么（信息、关系、立场、节奏、归属感）？
3. 这个动作在当前情境里是必要的吗？

三选一，**必须落在纸面**：

| 归因 | 处置 | 例子 |
|---|---|---|
| 承担功能 | **不动** | 公文"经常务会议通过"；随笔里孤立短句；学术 hedge |
| 不承担且与情境冲突 | **可改** | 邮件里的空泛评价句；新闻里无来源的"专家认为" |
| 不承担但不冲突 | **可留**（风格自由） | 个人习惯的过渡词；同义反复的口头习惯 |
| 无法判断 | **进待查**，不修改 | 需要外部材料才能判断的指涉 |

### 第 4 步：缺口定位（替代"像不像 AI"）

只查三处缺口，它们对应提示词/情境最常丢的维度：

| 缺口 | 判据 | 不是判据 |
|---|---|---|
| 指涉缺口 | 此处需要可核对象（人、数、时间、文件），文本里没有，或用评价替代 | 指涉密度高低本身 |
| 读者缺口 | 文本假设了读者不具备的背景，或重复了读者已知的内容 | 篇幅长短 |
| 后果缺口 | 承诺、条件、例外、责任被抹平或加重 | 语气强弱 |

### 第 5 步：效果验证（改完之后）

- **保义五轴**：实体与专名、数字与单位、否定辖域、关系方向、承诺与把握。逐条核，不用相似度分数。
- **读者任务**：给目标读者一个具体任务（找到某个决定、复述某个条件、判断要不要照做），看是否达成。
- **禁用**：检测器分数、"像人"统计指纹（句长分布、困惑度、词汇多样性）、BLEU/ROUGE/SARI 作质量判据。

## 3. 判定表（可直接照做）

| 现象 | 先查 | 处置 |
|---|---|---|
| 通篇"本文旨在／综上所述" | 是否只剩框架、没有具体内容 | 改内容，不删框架词 |
| 每句都对、整段读不下去 | 分句结构（文献：连贯问题 69.34% 在分句） | 重排分句，不加"因此/然而" |
| 读完不知道谁负责、什么时候、多少钱 | 指涉缺口 | 要求补材料；无材料则标缺，不许编 |
| 改完像另一个人写的 | 归属感（逐句改 vs 逐段改的差异有文献） | 降粒度，改段落不改句子 |
| 学术稿被改得油滑 | hedge 是把握标记 | 不动 hedge |
| 邮件改得像命令 | 请求力度与决定权 | 保留"如果方便"一类软化 |
| 文稿节奏均匀、没有起伏 | 内容是否有推进 | 有推进则改结构；无推进则先补内容 |
| 大量重复 | 重复是否组织关系/表情绪 | 有功能则留；纯填充则删 |

## 4. 记录格式（每处修改一条）

```
位置：第 3 段第 2 句
原文：……
情境卡：作者=项目维护者；读者=使用者；目的=告知变更；后果=误用会出错
功能归因：该句承担"免责"功能（说明兼容范围）
判定：承担 → 不动
```

没有"功能归因"的修改记录，视为未完成判断。

## 5. 这套方法为什么不会随模型迭代失效

模型变的是 L3 的分布位置：句子变长变短、评价词变多、语气变客气、开始用 emoji、开始写小标题。
这些都在"形式"层，且都可以被提示词与训练偏好改写。

方法锚在 **L3 ← L2 ← L1** 的对应关系上：

- 一条改稿判断的理由永远是"此处需要/不需要这个功能"，不是"模型爱这么写"。
- 因此新模型出现时，只需重跑第 2–4 步，不需要更新规则库。
- 反过来说，如果将来出现"形式完全由情境决定、却仍被普遍判为机器"的现象，
  说明还有一维未被纳入（例如作者身份线索），那时要把"归属"作为独立维度加进来，而不是改判据。

**它会在什么情况下失效**（写在这里以便被推翻）：

1. 若厚情境实验显示：给了真实材料与读者信息，AI 文本仍在结构层系统性偏离人类，且偏离与情境无关 → 需要新增篇章层机制。
2. 若读者实验显示：几何指标（η²、silhouette、篇内半径）与"可感人味"无相关 → 说明这些指标只描述分布，不描述体验，方法仍需读者端证据。
3. 若某体裁内人类文本本身高度同质（如法条、标准条款），此法的"改变"空间极小——这是正确结果，不是失效。

## 6. 已被否证的替代路线（不要再走）

| 路线 | 否证 |
|---|---|
| 禁用词表 / 评价词密度 | 同体裁对照 AUC 0.69；大厂中文 README 同样满是"开箱即用/一站式" |
| 句长阈值、标点密度阈值 | 无中文成人整稿验证；随机文本也能出现长程相关 |
| 结构模板标记（emoji 标题、特性表格） | 与筛选条件循环，不能作独立判据 |
| 困惑度 / burstiness 检测 | 法条体裁人类文本落入模型区间，FPR > 60% |
| 以"通过检测器"为目标 | 检测器随模型、语言、粒度翻转；且目标本身错位 |
| 单一"人味分数" | 各维度方向可相反（正式度↑ 但节奏↓），一维打分必然掩盖冲突 |

## 7. 一页操作卡（修订版）

```
1 写情境卡（六项；缺项只作风险标记，不作修改许可）
2 查三处缺口：
   指涉——这里需要的可核对象（人/数/时间/文件）在不在
   读者——读者已知/需知的前提有没有被写掉或重复
   后果——承诺、条件、例外、责任有没有被抹平或加重
3 只对命中的缺口动手；动之前问否决权：
   该形式是否承担功能（承担 → 不动；不承担 ≠ 该改）
4 改完核保义五轴 + 读者任务（如果有读者）
5 记一条记录：位置 / 原文 / 情境 / 缺口类型 / 判定
```

与初版的差别：初版把"不承担功能"当成修改理由，实测会放大风格偏好；
现在只有**缺口**能产生修改动作。

## 8. 能力边界（压力测试的结论，必须写清）

| 能判 | 判不了 | 原因 |
|---|---|---|
| 文内自洽（指代落空、条件缺主句、前后矛盾） | 节奏好坏、声音像不像、陈套与否 | 这些需要读者任务或作者归属信息 |
| 面向明确任务时缺哪些执行要素 | 这段话"是否机器味重" | 该问题没有稳定判据（词表 AUC 0.69，检测器跨体裁失效） |
| 指涉是否有出处、是否可核 | 片段是否代表全篇 | 判定单位不同；片段只能判内部一致性 |
| 修改是否保住五个硬轴 | 改完后读者会不会更喜欢 | 需要读者实验 |

"待查"的三条硬规定（初版缺失，实测中它吞掉了 4/5 案例的关键维度）：

1. 必须写明**要查什么**（哪份文件、哪个规范、哪个版本）；
2. 必须写明**查到什么程度可以结案**；
3. 超过约定时间未查到 → 升级为"无法判断并交作者"，**不得**用风格偏好填补。

## 8b. 与实验结果的对应（2026-10-25）

厚情境实验把"改什么"分成了两层：

| 层 | 缺口类型 | 能做什么 |
|---|---|---|
| 内容层 | 指涉缺口（缺人/数/时间/文件） | 补材料即可解决；实验里指涉 4→28/千字 |
| 形式层 | 体裁原型化（句法/停延/词汇分布过窄） | **补材料无效**（η² 0.478→0.459）；只能通过改写句法结构，且会破坏作者声音 |

对方法的直接影响：
- "补材料"是唯一被实验证实有效的干预；
- 对形式层的修改（拆长句、加连接词、换词）没有任何实验支持，且与 ZH093/094 的语体合法性冲突；
- 因此**不要**把"读起来像范文"当成改风格的理由，只当"查缺口"的线索。

## 9. 与朴素基线的关系

诚实记录：实测 5 份文本，"修内部不一致 + 补缺失要素"的朴素规则与五步法在 4/5 上动作相同。
本方法的独特产出不是更准的判决，而是：

- 把判决写成可复核的记录（位置、情境、缺口类型、否决理由）；
- 把"无法判断"显式化，避免用风格偏好替代证据；
- 把"改什么"限制在能指认缺口的项上，降低过度修改。

如果只需要一个快速做法：**只查三处缺口，其余不动**。

## 10. 与文献的接口

本方法的每一条都能回到证据，不是自创规矩：

| 方法要素 | 依据 |
|---|---|
| 情境先于文本 | 语体由表达功能与情境共同制约（张伯江、方梅 1996；陶红印 1999/2007） |
| 功能先于形态 | 同形形式功能不同；省略、重复、破格可承担关系与立场（廖秋忠 1992；陈望道 2008；Cotgrove） |
| 指涉看来源 | 指称与可及性分层；颜色修饰语在特定任务中促进加工（徐赳赳 2005；RC006） |
| 保义五轴 | 极性/关系反转仍得高 BLEU；人类判"同义"一致性仅 κ≈0.74（c1-00、c1-03） |
| 禁用检测器 | 检测器跨模型方向相反；困惑度在法条失效（d2-00、d2-03、d2-04） |
| 改稿粒度影响归属 | 逐句建议归属感 −3.66，逐段 −5.65 但评分不同（d2-06） |
| 分句结构优先 | 1794 处标注中分句不当 69.34%（RC003） |
