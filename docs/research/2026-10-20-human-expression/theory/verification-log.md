## 0. 这轮做了什么

| 编号 | 检验 | 目的 | 结果 |
|---|---|---|---|
| E1 | 五体裁几何（全文） | 人机在体裁空间里的形状是否不同 | 人 silhouette ≈ 0；AI 0.17–0.81 |

## 1. 长度混淆（E2）——必须先处理的坑

| 批次 | 平均汉字 | 说明 |
|---|---|---|
| 人类 | 790.5 | 统一 800 字窗口 |
| v1 | 644.7 | 软性"约 800 字" |
| v2 | **256.1** | 实际输出远短于要求 |
| v3 | 679.8 | 硬字数下限，达标 |
| v4 | 645.5 | 仅 4 篇，S3 层 |

v2 只有 256 字，任何逐字频次、指涉密度、词汇多样性的跨批比较都会被长度放大。
处理办法：全部重测一次 250 汉字前缀窗口，报告两套结果，只在两套一致处下结论。

**在 250 字窗口下仍然成立**：人类 η² 更低、簇更重叠、篇内更分散；AI 更高、更成团。
**在 250 字窗口下被削弱**：人类体裁留一分类从 0.75 降到 0.62（样本变短，信息变少）。
后一条说明"人类体裁可分类性"本身依赖篇幅，不能当强证据。

## 2. 主结果（250 字窗口，n=60 人 / 60 / 57 / 60）

| 组 | η²(体裁) | 到自身中心 | 体裁中心间距 | 比值 | silhouette | 篇内半径 |
|---|---|---|---|---|---|---|
| 人类 | **0.244** [0.234, 0.292] | 4.00 | 3.44 | **0.86** | **−0.013** | 5.49 |
| v1 | 0.310 | 3.09 | 3.94 | 1.27 | 0.141 | 4.23 |
| v2 | 0.374 | 3.16 | 4.31 | 1.37 | 0.164 | 4.26 |
| v3 | 0.645 | 1.24 | 5.71 | 4.60 | 0.628 | 1.68 |

读法：人=宽而重叠；薄情境 AI=窄而分开；形式约束 AI=极窄极分开。
三者的排序在自助重采样下稳定，且不随窗口长度反转。

## 3. 第二领域复制（E4）

语料：项目文档，个人 README 7、大厂 README 16、产品落地页 6（共 29 篇；全部人类撰写）。

| 指标 | 值 | 与主研究对比 |
|---|---|---|
| η²(体裁) | 0.144 | 主研究 0.244，同向更低 |
| 到中心 / 中心间距 | 4.42 / 3.32 = **0.75** | 主研究 0.86 |
| silhouette | 0.037 | 主研究 −0.013 |
| 组内半径 | 5.18–7.02 | 主研究 5.49 均值 |

结论：**"体裁解释力有限、簇重叠"不是五体裁挑选造成的**。换了领域、换了采集管线，形状一致。

## 4. 反证：厚情境下指涉不塌陷（E5）

| 组 | 指涉/千字（中位） | 数字/千字 | 句长 CV |
|---|---|---|---|
| 人类个人/大厂 README（n=23） | 58.6 | 28.6 | 0.95 |
| **AI README（n=68）** | **45.9** | 23.0 | 1.22 |
| 人类落地页（n=6） | 23.7 | 12.8 | 0.96 |
| **AI PR 正文（n=70）** | **28.2** | 22.2 | 0.64 |
| AI 评审评论（n=7） | 22.1 | 16.6 | 0.70 |

**"AI 文本具体性塌陷"作为普遍命题被否证。**
在要求具体物的体裁里，AI 的指涉密度与人类同区间；此时 8–56/千字的巨大差距不再出现（主研究是 5%–26%）。

修正后的表述：指涉密度是**情境缺口的读数**，不是模型属性。
给世界就有指涉；没给世界，只能用评价词把句子填满。

同时注意：AI README 的句长 CV（1.22）高于人类（0.95），说明"篇内节奏均匀"也不是普遍命题——
README 里被代码块与列表切碎，CV 失去意义。**CV 只能在同类体裁、同一排版条件下比较。**

## 5. 被丢弃的指标（E7）

6-gram Jaccard 曾被用来证明"AI 文本彼此更像"：

| 组 | 体裁内重合 | 体裁间重合 |
|---|---|---|
| 人类 | 0.0070 | ~0 |
| v1 | 0.0030 | ~0 |
| v2 | 0.0035 | ~0 |
| v3 | 0.7495 | 0.0002 |

人类反而比 v1/v2 重合更多。原因：人类文章共享专名、机构、固定表述（"记者了解到"），
而 AI 换词更勤。**这个指标测的是"共享专名"，不是"同质化"。** 因此不再使用，
只在 v3 这种模板塌缩上作极端指示。

## 6b. 补充检验：体裁是不是离散类别（E8）

两两体裁分离度（体裁中心距 ÷ 两体裁平均半径；>1 表示能分开）：

| 组 | 最小 | 中位 | 最大 | <1 的对数 |
|---|---|---|---|---|
| 人类 | 0.63 | **0.95** | 1.29 | **6/10** |
| v1 | 0.97 | 1.26 | 2.40 | 1/10 |
| v2 | 1.02 | 1.42 | 2.30 | 0/10 |
| v3 | 2.69 | 5.05 | 7.27 | 0/10 |

人类最接近的一对是"求是 ↔ 新闻"（0.63），最远的是"公文 ↔ 随笔"（1.29）。
另外，人类按**发布媒体**分组的 η²（0.209）与按体裁分组（0.244）几乎相同——
说明"谁在写、写给谁"与"写什么体裁"解释力相当，体裁并未垄断形式差异。

## 6c. 数据质量修正（E9）：站点样板污染

在核对案例时发现：**S5 全部 12 篇的首行都是站点提示**（"您在使用一个旧版本的浏览器…"），
另有 3 篇含"（平台提示：本文可能是商业…）""转载请注明出处"。

影响：250 字窗口里被占 10–14%，直接抬高句数、压低指涉密度。
处理：在特征提取前按模式剔除站点提示行（`human_model.py` 的 `NOTICE`），全部指标重算。

重算前后对比（人类）：

| 指标 | 未剔除 | 剔除后 |
|---|---|---|
| η² | 0.246 | **0.227** |
| silhouette | 0.001 | **−0.017** |
| 到中心 / 中心间距 | 3.85 / 3.45 | 3.90 / 3.33 |
| 篇内半径 | 5.29 | 5.35 |
| 留一分类 | 0.617 | **0.667** |
| 随笔指涉密度 | 8.0 | 9.1 |

方向全部不变，人类一侧的"重叠"更强。**结论对这次污染稳健**，但必须记录：
任何网页采集语料都要先剔站点样板，否则体裁间比较会被固定样板拉平。

## 6d. 换表征重测（E10）：词面 n-gram、KMeans、内容遮蔽

不用 21 个自选特征，改用字符 2–4 gram TF-IDF（`analysis/independent_check.py`）：

| 组 | ARI(KMeans5 vs 体裁) | 同体裁 5 近邻（chance 0.19） | 内容遮蔽后 | 体裁内余弦距离 |
|---|---|---|---|---|
| 人类 | 0.65 | 0.83 | **0.49** | 0.854 |
| v1 | 1.00 | 0.97 | 0.72 | 0.842 |
| v2 | 0.92 | 0.91 | 0.57 | 0.861 |
| v3 | 1.00 | 1.00 | 1.00 | **0.096** |

结论修订：
- **"人类体裁簇重叠（silhouette≈0）"撤回**。词面上人类体裁可辨（ARI 0.65、纯度 0.83）；
  重叠只在 21 维等权标准化空间成立。
- **"篇内更分散"只在特征空间成立**。词面余弦距离人类 0.854 ≈ v1 0.842。
- **保留下来的方向**：人类体裁身份一半靠内容（遮蔽后 0.49），模型主要靠形式（0.57–1.00）；
  v3 是真塌缩（0.096）。

## 6e. 统计对抗复核（E11）

独立重跑（`review-statistical.md`）：η²/silhouette/半径的**排序**在 5 个随机特征半集、150/250/400 首窗、
末 250 窗、两种缩放、置换检验（1000 次，p<0.001）、n=9 子采样下均不翻转；
但 η² 的**量级**随特征子集在 0.15–0.24（人类）间变动。
危险项：AI→人类 5 近邻标签迁移只有 0.55/0.40/0.30（构念不对称）；
末 250 窗的 v3 出现退化（四个体裁篇内距离为 0）。

## 6f. 方法压力测试（E12）

五份真实文本实跑（`review-method.md`）：4/5 情境卡有关键维度无法由文本确定；
3/5 关键处置依赖外部信息；5/5 存在竞争性功能归因；
与朴素规则"修内部不一致+补缺失要素"在 4/5 上动作相同，唯一可能不同的是"后果缺口"。
→ 方法论据此收缩（见 methodology.md 修订摘要）。

## 6g. 韵律层（E13）

补上"节奏=句长"的层次错位（详见 [prosody-layer.md](prosody-layer.md)）：

| 指标 | 人类 | v1 | v2 | v3 |
|---|---|---|---|---|
| 双音词比 | 0.617 | 0.680 | 0.690 | 0.668 |
| 2–5 音节韵律短语比 | 0.222 | 0.124 | 0.169 | 0.170 |
| 韵律短语长 CV | 0.564 | 0.442 | 0.437 | 0.451 |
| 虚化成分/千字 | 45.6 | 35.6 | 29.3 | 30.3 |
| η²（韵律 9 项） | **0.484** | 0.639 | 0.465 | 0.951 |
| η²（句长 3 项） | 0.230 | 0.372 | 0.649 | 0.942 |

结论：韵律维度对体裁的解释力约为句长维度的两倍；AI 系统性更双音化（连随笔层也是）、
韵律短语更均匀、虚化成分更少。**阴性**：偶数音节短语比无方向（0.558 vs 0.523–0.574），
双步律在此测量中读不出，不得当判据。

## 6h. 分词正则缺陷（E14）

`CJK.fullmatch(w)` 用的模式是**单字符类** `[\u4e00-\u9fff]`，`fullmatch` 因此只能匹配单字；
jieba 的多字词全部被丢弃。受影响特征：`ttr`、`entropy`（实际按字计）、`nominal`（恒为 0）。
改为 `^[\u4e00-\u9fff]+$` 后全部重算：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 人类 η² | 0.227 | **0.244** |
| v1 / v2 / v3 η² | 0.315 / 0.358 / 0.617 | **0.310 / 0.374 / 0.645** |
| 人类 silhouette | −0.017 | **−0.013** |
| 篇内半径（人 / v1 / v2 / v3） | 5.35 / 3.95 / 4.07 / 1.41 | **5.49 / 4.23 / 4.26 / 1.68** |
| 人类留一分类 | 0.667 | **0.617** |

方向全部不变；`nominalization` 从"死特征"恢复为可用特征。这是本库第二次由复核发现的自伤性缺陷
（第一次是 S5 站点样板）。
