# 人的表达是怎么组织的：一个可测的模型（v4）

日期：2026-10-25（2026-10-25 晚经敌意复核修订，见 [review-synthesis.md](review-synthesis.md)）
性质：**测量框架 + 编辑程序**，不是新的汉语表达理论。
"形式由交际情境与功能制约"是功能主义／语体研究的既有主张（Halliday；张伯江、方梅 1996；陶红印 1999；冯胜利 2018）；
本稿的增量只有两点：把"体裁解释不了的那部分"测出来，以及据此给出可审计的改稿程序。
数据：五体裁人类 60 篇 × 三种生成条件（各 60，v2 有效 57）× 项目文档人机对照 29/68
脚本：`analysis/human_model.py`、`robustness.py`、`replication_docs.py`；结果 `analysis/*.json`

## 0. 一句话（复核后版）

> 可以测的不是"人的表达是情境的函数"这种一般命题，而是一个更窄的量：
> **文本里不能被体裁解释的那部分——本文称"情境载荷"——在人类写作中很大，在薄提示的模型输出中很小。**
> 差异出现的位置，与提示词丢掉的信息维度对应。

**2026-10-25 实验更新（预注册，见 [厚情境报告](../experiments/thick-context/report.md)）**：
给模型真实材料后，指涉密度 4.0→28.0（7 倍）、材料覆盖率 0.90，但 η² 只降 4%、ARI 不变、纯形式纯度完全相同。
所以模型要拆成**两层**：内容层随材料走，形式层不随材料走。本稿下面的"提示词压缩"只解释内容层。

支撑它的三条，复核后仍成立（数值见 §2，复核见 [review-synthesis.md](review-synthesis.md)）：

1. **体裁标签弱预测人类形式**：21 维 η² = 0.244；词面 ARI（KMeans 对体裁标签）= 0.65。
2. **模型输出几乎完全由体裁决定**：ARI = 1.00 / 0.92 / 1.00；内容遮蔽后的纯形式同体裁近邻比 0.72 / 0.57 / 1.00（人类 0.49）。
3. **具体性由材料供给**：薄情境 0.3–11/千字，厚情境 28.2–45.9，与人类 23.7–58.6 同区间。

被复核撤回的两条，见 §2 的表征对照。

## 1. 三层结构

| 层 | 内容 | 能否从文本直接读到 |
|---|---|---|
| L1 情境 | 作者是谁、写给谁、为什么写、什么媒介、什么后果、什么时间地点、手上有什么材料 | 部分可重建，常需外部信息 |
| L2 功能 | 该处要完成的交际动作：告知、说服、请求、免责、共情、记录、自证、留白 | 需读全文与语境 |
| L3 形式 | 句法、词汇、指涉、标点、篇章结构 | 可直接测量 |

本稿要检验的命题（**不是新命题**，功能主义与语体研究已有）：**L3 的取值由 L2 在 L1 中的取值决定**。
本稿的增量在于把它变成可测的量，而不是提出它。它能产出可测预测：

- 若成立 → 同一体裁内，不同 L1 取值的文本应当在 L3 上分散得足够大，以至于体裁不能把它们分开。
- 若成立 → 具体性应当随情境变化，而不是随文体变化。
- 若成立 → 脱离 L1、L2 直接对 L3 下判断（词表、句长、模板）必然不稳定。

## 2. 四条不变式与证据

### I1 体裁解释力有限（但**不是**"簇重叠"）

> **修订**：初稿写"人类体裁簇互相重叠（silhouette≈0）"，那是 21 个自选特征空间的产物。
> 换到字符 n-gram 词面后，人类体裁可识别度很高（ARI 0.65、同体裁 5 近邻 0.83、chance 0.19）。
> 正确的说法是：**体裁真实、但不决定**——它给出一半左右的结构，另一半由体裁之外的东西带来。

三种表征下的同一批文本：

| 表征 | 人类 | v1 | v2 | v3 |
|---|---|---|---|---|
| 21 维特征 η²（体裁解释方差） | **0.244** | 0.310 | 0.374 | 0.645 |
| 词面 ARI（KMeans k=5 对体裁标签） | **0.65** | 1.00 | 0.92 | 1.00 |
| 词面同体裁 5 近邻（chance 0.19） | **0.83** | 0.97 | 0.91 | 1.00 |
| **内容遮蔽后**（只留虚词与标点）同体裁 5 近邻 | **0.49** | 0.72 | 0.57 | 1.00 |
| 词面体裁内余弦距离（越大越分散） | 0.854 | 0.842 | 0.861 | 0.096 |

读法：
- 人类的体裁身份有一半来自**内容**（写什么），遮蔽内容后掉到 0.49；
- 模型的体裁身份主要来自**形式**（怎么写），遮蔽内容后仍 0.57–1.00；
- v3（硬字数约束）是真塌缩：余弦距离 0.096，等于近重复。

五个体裁（求是体／新闻／公文／技术博客／生活随笔），每体裁人类 12 篇，取统一 250 汉字窗口，
21 个形式特征（句法、指涉、人称、标点、词汇分布）：

| 组（21 维特征空间，仅此空间有效） | 体裁解释的方差 η² | 篇到自身体裁中心距离 | 体裁中心间距 | 间距/半径 | silhouette |
|---|---|---|---|---|---|
| **人类** | **0.244** [0.234, 0.292] | 4.00 | 3.44 | **0.86** | **−0.013** |
| AI v1 | 0.310 | 3.09 | 3.94 | 1.27 | 0.141 |
| AI v2 | 0.374 | 3.16 | 4.31 | 1.37 | 0.164 |
| AI v3（硬字数约束） | 0.645 | 1.24 | 5.71 | 4.60 | 0.628 |

方括号为 300 次自助重抽样的 95% 区间。

读法（**仅限这 21 维特征空间**）：体裁中心之间距离（3.44）比体裁内部半径（4.00）还小，
所以在这个空间里"两个体裁的典型文本"比"同一体裁的两篇文本"更像，留一分类只有 62%。

但这条**不能外推**：换到词面（上一张表），人类体裁的 5 近邻纯度 0.83、ARI 0.65，
说明体裁在字面上相当可辨。两个表征不矛盾——它们量的不是同一件事：
21 维把句法、节奏、指涉等**不同刻度强行等权标准化**，抹掉了词面携带的体裁线索。
因此本文只把 η² 与 silhouette 当"这组特征下"的描述，不当体裁的可辨性结论。

**体裁不是离散类别，而是一条带软边界的带。** 人类两两体裁分离度（中心距 ÷ 平均半径，>1 才算分开）：

| | S1 求是 | S2 新闻 | S3 公文 | S4 技术博客 | S5 随笔 |
|---|---|---|---|---|---|
| S1 求是 | — | 0.63 | 0.88 | 0.98 | 1.15 |
| S2 新闻 | | — | 0.93 | 0.72 | 1.04 |
| S3 公文 | | | — | 1.07 | 1.29 |
| S4 技术博客 | | | | — | **0.64** |
| S5 随笔 | | | | | — |

十对里六对 < 1：求是↔新闻、求是↔公文、求是↔博客、新闻↔公文、新闻↔博客、博客↔随笔都分不开。
只有"公文 vs 随笔"这类两端才真正拉开。同时，"按发布媒体分组"的 η²（0.209）与按体裁的 η²（0.244）几乎一样——
**谁在写、写给谁，与写什么体裁，解释力相当。**

对比 AI 两两分离度中位数（同一 21 维空间）：人类 0.95（6/10 对 <1）→ v1 1.26（1/10）→ v2 1.42（0/10）→ v3 5.05（0/10）。

第二领域复制（项目文档：个人 README 7、大厂 README 16、产品落地页 6，共 29 篇，采集管线完全不同）：

| 指标 | 值 |
|---|---|
| 体裁解释的方差 η² | 0.144 |
| 篇到中心距离 / 中心间距 | 4.42 / 3.32 → 比值 **0.75** |
| silhouette | 0.037 |

**在完全不同的语料上复现了同一形状**（注意：同为 21 维特征空间；词面表征下人类体裁可辨，见上表）。这不是五个体裁挑选出来的巧合。

### I2 具体性由世界供给

同长度（250 汉字）下的指涉密度（数字＋时间＋年份＋引号/书名号＋机构名，每千字）：

| 体裁 | 人类 | v1 | v2 | v3 | AI/人 |
|---|---|---|---|---|---|
| 求是体 | 43.7 | 2.3 | 3.7 | 4.3 | 5%–10% |
| 新闻 | 43.0 | 3.7 | 11.0 | 1.3 | 3%–26% |
| 公文 | 56.3 | 10.0 | 5.9 | 8.3 | 10%–18% |
| 技术博客 | 23.6 | 2.3 | 2.0 | 0.7 | 3%–10% |
| 生活随笔 | 9.1 | 0.3 | 1.0 | 0.7 | 3%–11% |

人类在同一批文本里跨度 9.1–56.3（6.2 倍），说明这个量随情境走，而不是随文体走。

**但这条有边界，而且是本稿最重要的一次自我否证**：
在"提交 PR / 写 README"这类情境里，AI 文本的指涉密度并不塌陷——AI README 45.9 vs 人 58.6，
AI PR 正文 28.2 vs 人落地页 23.7。**差别消失了，因为体裁本身要求具体物（版本号、命令、路径、issue 号）。**

结论修正：指涉不是"AI 的天性"，而是**情境缺口的直接读数**。给了世界，它就会指涉；没给世界，它只能用评价填。

### I3 多余可以有功能

文献层结论，本库无独立实验，仅登记：

- 重复可组织关系、表情绪、形成节奏；排比不必三句，对偶不只表对立（陈望道 2008，161–165）。
- 省略主语在操作语体中可以是规范（陶红印 2007）。
- 即时通讯样本中中文省略号 47.7% 表"暗示"（Cotgrove，描述性，107 token）。
- 逐词把双音正式词换成单音口语词会不合语法："种植花""进行改"（ZH093/094）。

因此：**形态冗余 ≠ 表达冗余**。任何删减判断都要先问该形式在这里做什么。

### I4 篇内不均匀

早期数据：人类句长 CV 0.51–0.67（五层），AI 0.14–0.27。
但这条**不能独立使用**：文献已给出反例——随机文本也能出现句长长程相关（H 最高 0.89），
且强制简明的法条让人类文本落入与模型相同的低困惑度区间（Banerjee 2026，三个检测器 FPR > 60%）。
所以 CV 只能作组间描述，不能作个体判据。

## 3. 和 AI 味的差别在哪

### 3.1 模型

> AI 文本是**提示词的函数**，而提示词是情境的**有损压缩**。
> 差异不会均匀分布，而会集中在压缩丢掉的那几维。

提示词通常编码：体裁、主题、篇幅、风格要求。
提示词通常不编码：读者的实际知识状态、这件事的后果、作者要承担的责任、历史与互文、手上的真实材料。

于是可测结果是：

| 提示词编码了什么 | 可测后果 | 本库证据 |
|---|---|---|
| 体裁 | 体裁被**放大成原型**：η²↑、簇分开、篇内变窄 | η² 0.24 → 0.31–0.37；silhouette −0.01 → 0.14 |
| 篇幅 | 篇幅达标但结构模板化 | v3：η² 0.65、silhouette 0.63、篇内半径 1.68（人 5.49）、6-gram 重合 0.75（人 0.007） |
| 真实材料 | 指涉回升到人类区间，但**形式层不动** | 实验：4.0→28.0（7×）；η² 0.478→0.459；ARI 0.514→0.516 |
| 体裁标签 | **决定形式层**：去掉标签，原型化大幅下降 | 2×2 实验：η² 0.456→0.342；ARI 0.566→0.338；纯形式 0.547→0.393 |
| 读者与后果 | 无直接测度，但它是解释"为什么读起来空"的最后一维 | 待测（见 §5） |

**哪一段是测出来的、哪一段是推断，要分开：**

- 测到（21 维空间）：人类 5/10 对 <1、AI 1/10、模板组 0/10；词面上人类 ARI 0.65、AI 0.92–1.00；薄情境指涉塌陷、厚情境不塌陷；硬字数约束放大原型化。
- 推断：原因是"提示词把体裁说死、把情境省掉"。这一步没有直接操纵实验，只有自然对照。
- 因此下面的可判伪预测必须做：**给模型真实材料与读者信息后，分离度与 silhouette 应回到人类区间**。

另一个细节值得记下：人类**强规范体裁（公文）内部最分散**（篇内半径 4.46，五体裁最高），
因为"公文"底下还有通知、报告、批复、函，发文机关与事由各不相同；
而 AI 的公文组反而最窄（3.09）。**规范越强，人类越是靠文种与事由分化；模型则越向单一原型收敛。**

### 3.3 两层分离（实验结论）

预注册的厚情境对照（5 体裁 × 6 主题 × 2 条件，同模型、同篇幅、只改信息供给）给出一个干净的分割：

| 层 | 指标 | 薄 → 厚 | 判定 |
|---|---|---|---|
| 内容层 | 指涉密度、材料使用 | 4.0 → 28.0；覆盖率 0.90 | **随材料变** |
| 形式层 | η²、KMeans-ARI、纯形式纯度 | 0.478 → 0.459；0.514 → 0.516；0.473 → 0.473 | **不变** |

> **更正（2026-10-25，剂量实验）**：本表原写"评价词 7.7 → 6.4"，暗示套话被具体项替代。
> 保留情境骨架、只改材料条数后，评价词率是 5.2 / 6.4 / 5.9 / 7.1（0/2/5/10 条），**不随材料下降**。
> 三组放在一起才看清：无任何情境 7.7 → 只有骨架、无事实 5.2 → 骨架＋5 条 5.9。
> **压掉评价填充的是骨架（身份、读者、后果），不是材料条数。**
> 剂量曲线：指涉中位 4 → 20 → 28 → 40，覆盖率 0.67 → 0.99 → 1.00，模型给多少用多少；
> 按体裁看，S1–S4 在 5 条已到人类水平，S5 随笔 2 条就超人类四倍。
> 见 [dose-response](../experiments/dose-response/report.md)。

因此："提示词是情境的有损压缩"只解释内容维。
**形式层是第二个机制，而它是提示词里说出来的体裁标签**——不是"模型偷偷选了体裁"。

形式层实验（2×2：体裁说明说 × 材料给不给，120 次生成）把这一层切开了：

| 单元 | 体裁提示 | 材料 | η² | ARI | 纯形式纯度 |
|---|---|---|---|---|---|
| A | 明说 | 给 | 0.456 | 0.566 | 0.547 |
| B | 明说 | 不给 | 0.411 | 0.566 | 0.447 |
| C | 不说 | 给 | 0.342 | 0.338 | 0.393 |
| D | 不说 | 不给 | 0.270 | 0.162 | 0.293 |

读法：

- **体裁标签贡献 0.114 的 η²（A→C），是材料贡献（C→D 0.072）的近两倍。**
  形式同质化的大头来自"你要求它写这个文体"，而这是任务契约，改写改不掉。
- 材料**不是**形式中性的：材料包里的"身份：区防指办""读者：各区县政府"本身在指认公文（C 比 D 高）。
- 不说体裁时，文种自述词出现率为 0——模型没有"自己选文体"的行为，所以"训练先验压过指令"这一说法缺乏证据，撤回。

先前把它归因为"训练数据里的体裁先验"，方向错了：**先验贡献的是语言底色**
（韵律四单元几乎不动：双音词比 0.659–0.665、2–5 音节短语比 0.208–0.235），
**不是体裁原型**。体裁原型跟着提示走。

这条模型同时解释了三件此前分开看的事：

- **为什么检测器会失效**：法条、专利这类"强制简明＋事实密集"的体裁里，人类文本的表层统计与模型重合。
- **为什么词表不灵**：词是 L3 的末端，被 L1/L2 决定；同一个词在不同情境里功能相反。
- **为什么"AI 味"有时浓有时淡**：浓淡取决于提示词丢掉的那几维在这个体裁里占多大分量。

### 3.2 一句话对照

| | 人类 | 模型（薄情境） |
|---|---|---|
| 变异来源 | 情境 × 个人 × 体裁 | 体裁 × 主题 |
| 分布形状（21 维） | 中心距 < 半径，簇重叠 | 簇分开、半径小 |
| 体裁一致性（词面 ARI） | 0.65 | 0.92–1.00 |
| 体裁身份来源 | 一半靠内容（遮蔽后 0.49） | 主要靠形式（0.57–1.00） |
| 具体性 | 由世界供给，随情境 6 倍变化 | 由提示词供给，无则用评价填充 |
| 冗余 | 可承担功能 | 多为补位 |
| 判断依据 | 形式能否追溯到功能 | —（本文不给模型侧判据） |

## 4. 这个模型怎么用（判定，不是打分）

三步，每步都可能得出"不改"：

1. **情境重建**：作者、读者、目的、媒介、后果、材料。
   缺哪一项就标缺，不许用"一般来说"补。
2. **功能归因**：对每个可疑形式问"它在这里做什么"。
   三种答案：承担／不承担／无法判断。
3. **缺口定位**：只处理"不承担且与情境冲突"的形式；"不承担但不冲突"是风格自由；
   "无法判断"进待查，不进修改。

在这套判据下，**"像不像 AI"完全不参与判断**。这是它能在模型迭代后继续用的原因：
新模型改变的是 L3 的分布位置，不改变"L3 必须能追溯到 L2/L1"这条关系。

完整方法与失效条件见 [methodology.md](methodology.md)。

## 5. 边界与未决

| 边界 | 影响 |
|---|---|
| 单一模型（GPT-6.1 Sol），DeepSeek 未取得；v4 仅 4 篇 | 跨模型推广不成立，只能作"一种对齐模型的样本" |
| 人类样本 60 篇、每体裁 12 篇、单一 250 字窗口、来源有限 | η² 的绝对值不稳，但组间排序稳定（自助区间不重叠） |
| 体裁标签来源不同：人类按来源归类，AI 按提示词指定 | 可能高估 AI 的 η²（提示词把体裁说得很明确） |
| 21 维特征偏表层 | 只操作化了"表层词句分布"，未操作化"表达"：韵律（汉语里是语法问题，不是句长）、管界、指称可及性、语体合法性（单双音/组配）、元话语类型、作者声音/归属、互文、文种/事由都没进模型 |
