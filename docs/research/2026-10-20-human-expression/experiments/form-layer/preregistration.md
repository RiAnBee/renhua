# 预注册：形式层实验（体裁提示 × 材料供给，2×2）

日期：2026-10-25　｜　本文件先于任何生成写定

## 1. 问题

厚情境实验已把模型切成两层：材料改变内容层（指涉 4→28/千字），
但不改变形式层（η² 0.478→0.459、ARI 0.514→0.516、纯形式纯度 0.473→0.473）。

**本实验问：形式层（体裁原型化）到底由什么决定？**
候选：① 提示词里明说了体裁；② 模型自己从主题/读者/材料推断体裁并照模板写（训练先验）。

## 2. 设计

| 因子 | 水平 |
|---|---|
| 体裁提示 | **明说**（"写一篇防汛通知"）／**不说**（"围绕防汛写一篇约 700 字的文字"） |
| 材料供给 | **给**（身份+读者+5 条材料+后果）／**不给** |

| 单元 | 体裁提示 | 材料 |
|---|---|---|
| A | 明说 | 给 |
| B | 明说 | 不给 |
| C | 不说 | 给 |
| D | 不说 | 不给 |

5 体裁 × 6 主题 × 4 单元 = **120 次生成**，每单元 1 次。
模型 `gpt-6.1-sol`，接口默认温度，提示词后缀（格式要求）四组完全相同。

与上一实验的关系：A ≡ 上一实验的 thick，B ≡ thin；C、D 为新增。同批重跑以排除漂移。

## 3. 预测

| 假设 | 预测 | 若成立说明 |
|---|---|---|
| **H-F1 提示驱动** | C 的 η² ≤ 0.30，或比 A 低 ≥ 0.10；C 的纯形式纯度 ≤ 0.40 | 去模板化**可以通过指令实现** |
| **H-F2 先验驱动** | C 的 η² ≥ 0.40 且与 A 相差 ≤ 0.05；C 的纯形式纯度 ≈ A | 模型会自己认体裁，指令改不动 |
| **H-M 材料独立** | 指涉密度 C ≥ 2×D，A ≥ 2×B | 材料效应与体裁提示无关（复现上一实验） |

人类基线（同 250 字窗口）：η² 0.244、ARI 0.65、纯形式纯度 0.49、指涉 9.1–56.3/千字。

补充判据（不参与主判定，只作解释）：C/D 组里**文种自述词**（通知/通报/现就…通知如下/本报讯/记者获悉/综上）
的出现率。若"不说体裁"仍自发出现文种词，即为体裁先验的直接证据。

## 4. 主指标

同既有管线：21 维特征 η²、KMeans-ARI、内容遮蔽后的同体裁 5 近邻（纯形式纯度）、
指涉密度、韵律（双音词比、2–5 音节短语比）、句长与 CV。

## 5. 判据（写死）

1. 四单元各自 ≥ 25 篇通过闸门，否则报告并停止主判定。
2. 主判定只看 A 与 C（材料都在、只差体裁提示）：
   - **H-F1 支持**：η²(C) ≤ 0.30，或 [η²(A) − η²(C) ≥ 0.10 且 ARI(C) ≤ ARI(A) − 0.10]。
   - **H-F2 支持**：η²(C) ≥ 0.40 且 |η²(A) − η²(C)| ≤ 0.05。
   - 其余：部分支持，报告数值，不选边。
3. 材料效应：指涉中位 C ≥ 2×D 且 A ≥ 2×B → H-M 成立；否则记录为未复现。
4. 纯形式纯度与韵律只作旁证，不单独改判。

## 6. 排除

汉字 < 400；含"作为AI/以下是"；含 Markdown 结构（标题、列表、代码块）。排除比例 > 20% 的单元作废。

## 7. 样本量与局限（事先承认）

每体裁每单元 6 篇：η²/ARI 仍属小样本，判据里已用"或/且"降低假阳性，
但单次采样的波动可能达 ±0.05。四单元同批生成可部分抵消漂移。

单模型、单次采样、合成材料，与上一实验相同。
