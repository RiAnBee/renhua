# 预注册：剂量反应实验（材料 0 / 2 / 5 / 10 条）

日期：2026-10-25　｜　本文件先于任何生成写定

## 1. 问题

厚情境实验证明了材料能抬起指涉密度（4→28/千字），但没回答**要多少条才够**。
如果 5 条就已经进入人类区间、10 条不再增加，那对 Skill 的可操作含义是
"向作者要材料时，问 3–5 个具体项即可，不必追问细节"；若非，则材料仍是主要瓶颈。

## 2. 设计

沿用同一批 30 个条目（5 体裁 × 6 主题）。**体裁一律明说**（上一实验证明形式层跟着体裁标签走，
这里要测的是内容层，不重复操纵形式）。

四档材料条数：**0 / 2 / 5 / 10**。5 体裁 × 6 主题 × 4 档 = **120 次生成**。

情境骨架（身份、读者、读者已知、后果）四档**完全相同**，只有「可用材料」的条数变化。
因此：

- d0 ≠ 上一实验的 thin（thin 连身份/读者/后果都没有）。d0 只缺事实材料。
- d2 = 前 2 条，d5 = 前 5 条（与上一实验 thick 同一组），d10 = 全部 10 条。
- 第 6–10 条为本轮新增，写法与既有 5 条同风格（数字、时间、机构、至少一条限制或负面事实）。

## 3. 预测

| 假设 | 预测 | 若成立说明 |
|---|---|---|
| **H-D 指涉随剂量升** | 指涉密度 ref(d) 单调升，d0 < d2 < d5 | 材料条数是指涉的剂量变量 |
| **H-S 在 5 条饱和** | ref(10) − ref(5) < 达到 ref(5) 总增益的 25% | 问 3–5 条即可，追问收益递减 |
| **H-E 评价词被替代** | 评价词率 eval(d) 单调降 | 内容层是替代关系，不是叠加 |
| **H-F 形式不动** | 句长、双音词比在四档间波动 < 0.02 | 形式层与材料无关（复现上一实验） |
| **H-N 无材料＝编造** | d0 的"材料外数字"率最高，d5/d10 接近 0 | 材料的作用之一是抑制编造 |

## 4. 主指标

1. **指涉密度**：数字、时间、年份、引号、机构名正则命中数 / 千字（沿用既有实现）。
2. **材料外数字率**：文本中的阿拉伯数字串，若不出现在该次供给的材料里，计一次；/千字。
   （中文数字不入统计，已知低估。）
3. 覆盖率：可用材料 token 在正文中的命中比例（分母随档位变，只作过程检查）。
4. 评价词率、句长、CV、双音词比、2–5 音节短语比。

人类基线：指涉 9.1–56.3/千字（中位 22.3）。

## 5. 判据（写死）

设 g1 = ref(2) − ref(0)、g2 = ref(5) − ref(2)、g3 = ref(10) − ref(5)。

1. 四档各 ≥ 25 篇通过闸门，否则报告并停。
2. **H-D 成立**：ref(2) > ref(0) 且 ref(5) > ref(2)，两个差都 ≥ 2/千字。
3. **H-S 判定（饱和点）**：
   - g3 < 0.25 × (g1 + g2) → **在 5 条饱和**。
   - g3 ≥ 0.25 × (g1 + g2) 且 g3 ≥ 2/千字 → **10 条仍未饱和**。
   - 其余 → 说不清，报曲线。
   另做 log 拟合 ref = a + b·ln(1+d)，报 b、R² 与边际收益降至 0.5/千字时的 d。
4. **H-E**：ref 升且 eval(5) < eval(0)，两条件同时满足才算。
5. **H-F**：四档句长极差 < 8 字、双音词比极差 < 0.02。
6. **H-N**：d0 的材料外数字率 ≥ 2× d5，且 d5 ≤ d2。

## 6. 排除

汉字 < 400；含"作为AI/以下是"；含 Markdown 结构。同一档排除 > 20% 作废该档。

## 7. 局限（事先承认）

- 事实是合成的，条数的"信息量"未必等值：第 6–10 条由本轮补写，密度与第 1–5 条相近但不保证。
- 每格 6 篇/体裁，剂量是组间比较（非同一篇的剂量），篇间波动与剂量效应会混在一起。
  这是设计上的主要弱点，写报告时要写明，不用显著性去粉饰。
- 单模型、单次采样。
- 数字正则只捕阿拉伯数字，中文数字与"三天""两小时"这类表达不入账。
