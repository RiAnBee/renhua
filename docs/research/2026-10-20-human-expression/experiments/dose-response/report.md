# 剂量反应实验报告（材料 0 / 2 / 5 / 10 条）

2026-10-25　模型 `gpt-6.1-sol`　120 次生成（4 档 × 30）　预注册见 `preregistration.md`

## 结论

1. **总量上，10 条仍未饱和。** 指涉中位 4 → 20 → 28 → 40/千字，增益 16 / 8 / 12；
   log 拟合 ref = 3.67 + 14.62·ln(1+d)，R² 0.992，但实际更接近线性。
   H-D 成立、H-S 判为"未饱和"。
2. **但"饱和"是体裁问题，不是总量问题。** 按体裁对照人类同体裁基线，
   公文/新闻/理论在 5 条时已到人类水平（S3 40 对 48，S2 42 对 38，S1 48 对 44），
   技术博客 5 条已达人类（22 对 18.3），**随笔 2 条就超过人类四倍**（16 对 4.5）。
3. **模型不按体裁节流，照单全收。** 材料覆盖率 0.67 → 0.99 → 1.00，
   给多少用多少；人类随笔极少写数字，模型给 10 条就写 24。
4. **H-E（评价词随材料增加而减少）被否。** 评价词率 5.2 / 6.4 / 5.9 / 7.1，
   不随材料下降，10 条时还升。跨三个条件放在一起才看清发生了什么：

   | 条件 | 身份/读者/后果 | 事实材料 | 评价词/千字 |
   |---|---|---|---|
   | thin（旧） | 无 | 无 | 7.7 |
   | d0 | 有 | 无 | 5.2 |
   | d5 ≈ thick | 有 | 5 条 | 5.9 |

   **压掉评价填充的是情境骨架，不是材料条数。** 旧报告里 7.7→6.4 的下降，
   绝大部分来自骨架那一半，材料那一半是噪声（5.2→5.9，方向还反了）。
   这项跨实验对照是事后看的，不参与预注册判定。
5. **H-F 判为通过，但卡在边界。** 句长 46.0 → 41.8 → 38.7 → 39.4（极差 7.3，阈值 8）；
   双音词比 0.673 → 0.667 → 0.654 → 0.654（极差 0.019，阈值 <0.02）。
   两者都只差一点，且**换掉 2 篇样本就能翻转判定**（见 deviations 第 7 条）——
   实质结论是"形式层对材料只有 2% 级的漂移"，不要把这个通过当成硬结论。
6. **H-N 无法判定。** 材料外数字率四档全为 0.0–0.1/千字——
   因为提示词本身禁止编造，d0 靠"干脆不写数字"达成，不是靠材料。
   这个指标设计失效，不是假设被证。

## 解读

**这轮把"补材料"这件事的收益曲线画出来了，同时否掉了两个附带假设。**

- 内容层对材料的响应是**近似线性**的，没有出现"给几条就够"的公共拐点。
  原因不在信息效率，而在**模型的使用方式**：覆盖率 1.00 意味着它把每条材料都写进去。
  人类不是这样——人类按体裁决定写多少细节，随笔几乎不写数字。
- 所以"饱和"的正确表述是**按体裁饱和**：S3 要到 5–10 条才接近人类（48），
  S5 在 2 条就超了四倍。用同一个剂量喂所有体裁，必然一部分不够、一部分过量。
- **评价词不因材料增加而减少**，这修正了上一轮由 thin→thick 推出的"替代关系"。
  上一轮看到的 7.7→6.4 是噪声；真实的差别是**具体项的密度**，不是"套话被挤掉"。
  这条对 Skill 有直接影响：不能靠"多要材料"来消掉套话。
- 形式层（句长、双音词比）随剂量有 2% 级的漂移，但远小于体裁带来的差异，
  与"形式层跟体裁标签走、不跟材料走"一致。

## 对 Skill 的含义

1. **要材料的数量和体裁绑定，不给统一数字。** 公文/新闻可以要 5 条以上；
   随笔给 2 条就够，给 10 条会把随笔写成工作日志。
2. **要材料的目的是"具体项"，不是"去套话"。** 套话需要单独判据处理（功能归因）；
   要压套话，先补情境骨架（我是谁、写给谁、出错会怎样），骨架的效力是材料的数倍。
   指望材料挤掉套话是错的。
3. **模型会把每条材料都写进去**，所以编辑时真正要问的是"这条材料在这个体裁里该不该出现"，
   而不是"材料够不够"。
4. **不要用"数字多"当具体性指标**：S5 人类 4.5/千字，模型 20——数字密度高在这里恰恰是不像人。

## 判据执行

按预注册 §5：四档 n=30 均过闸门。g1=16.0、g2=8.0、g3=12.0；
g3 ≥ 0.25×(g1+g2)=6.0 且 g3 ≥ 2 → **10 条仍未饱和**。
H-E、H-N 为否/无法判定，H-F 边缘不通过。判据未事后修改。

## 局限

- 四档为组间比较，不是同一篇的剂量梯度；篇间波动与剂量效应混在一起。
- 第 6–10 条为本轮补写，与第 1–5 条风格相近但信息密度未做配平。
- 人类逐体裁基线（n=12）是本轮后补计算，仅作对照，未参与预注册判定。
- 数字正则只捕阿拉伯数字。
