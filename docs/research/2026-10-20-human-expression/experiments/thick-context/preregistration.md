# 预注册：厚情境对照实验（2026-10-25）

> 这份文件在生成任何文本**之前**写定。任何偏离都要记入 `deviations.md`，不得事后修改判据。

## 1. 问题

"提示词是情境的有损压缩"这一说法，目前只有自然对照（不同体裁、不同材料可得性）。
本实验只操纵**一个变量**：提示里给不给真实材料、读者状态、后果与责任边界。

## 2. 假设

- **H1（材料→具体性）**：同一体裁、同一主题下，厚情境文本的指涉密度显著高于薄情境，且材料被实际使用。
- **H2（材料→体裁原型化减弱）**：厚情境的体裁解释力（η²）、体裁一致性（ARI）、纯形式纯度下降，向人类区间移动。
- **H3（材料→篇幅与节奏不变）**：句长均值、句长 CV 不发生方向性变化（材料改变的是内容供给，不是句法偏好）。
- **H0（零假设）**：厚薄两条件在上述指标上无差异；若成立，说明差异来自模型侧而非情境供给，"有损压缩"说法被削弱。

## 3. 设计

| 项 | 设定 |
|---|---|
| 模型 | `gpt-6.1-sol`（与既有 v1/v2/v3 语料同族），单一模型 |
| 体裁 | 5（求是体、新闻、公文、技术博客、生活随笔） |
| 主题 | 每体裁 6 个，取自既有 `prompts_v2.jsonl` 的前 6 个，主题之间互不重叠 |
| 条件 | 薄（既有 v2 提示词形状）/ 厚（同提示 + 情境包） |
| 单元 | 5×6×2 = **60 篇/条件**，共 120 次生成，每单元 1 次 |
| 温度 | 使用接口默认值（记录返回值）；不逐样本重采样 |
| 长度 | 提示词要求 700–800 字；分析统一取前 250 汉字窗口，并报告全文长度 |

**薄提示**：体裁 + 主题 + 篇幅 + 格式要求（禁用标题/列表/Markdown/工具）。
**厚提示**：薄提示 + 情境包：身份、读者、5 条具体材料（含至少 1 条限制/否定项）、读者已知、后果。
情境包只增加信息，不改格式要求。

材料为**合成但内部一致**的事实（不含真实个人隐私）；实验测的是"信息供给是否改变文本形状"，不是材料真实性。

## 4. 指标（全部预注册）

### 主指标

| 编号 | 指标 | 定义 |
|---|---|---|
| P1 | 指涉密度 | 数字、时间、年份、引号/书名号、机构名，每千汉字（250 字窗口） |
| P2 | 材料覆盖率 | 情境包 5 条材料中，关键 token 在原样出现的条数 / 5 |
| P3 | 体裁解释力 | 21 维特征上按体裁分组的 η² |
| P4 | 体裁一致性 | 字符 2–4 gram TF-IDF 上 KMeans(k=5) 与体裁标签的 ARI |
| P5 | 纯形式纯度 | 内容遮蔽（只留虚词与标点）后，同体裁 5 近邻比例 |

### 次指标

句长均值、句长 CV、评价词密度、篇内余弦分散度、全文汉字数。

### 人类基线

既有 60 篇人类语料（每体裁 12 篇，250 字窗口）：P1 = 9.1–56.3/千字；P3 = 0.227；P4 = 0.65；P5 = 0.49。

## 5. 判据（事先写死）

| 结果 | 判定 |
|---|---|
| P1 厚 ≥ 2×薄，且 P2 均值 ≥ 0.6，且（P3 相对薄下降 ≥ 30% 或 P4 下降 ≥ 0.10） | **H1+H2 支持**："材料供给即恢复情境载荷" |
| P1、P2 达标，但 P3/P4 不变 | **H1 支持、H2 反驳**：具体性可补，体裁原型化是模型侧惯性 |
| P1 未达 2× 或 P2 < 0.3 | **H1 反驳**：材料未被使用，问题不在信息供给 |
| 厚条件出现长度崩塌（< 400 汉字）或格式违规 | 该单元剔除并记录；剔除 > 20% 则该体裁作废 |
| 两条件 P1/几何均无差异 | **H0**：模型的差异不来自情境供给，理论需重写 |

配对分析：同一主题的厚/薄配对，报告每对差值的中位数与符号检验；不做事后分组。

## 6. 排除与偏离

- 排除：拒绝回答、含"作为AI/以下是"、含 Markdown 结构、汉字 < 400。
- 记录：每次调用的 model 返回值、usage、时间戳、重试次数、任何截断。
- 不做事后加指标；若发现新现象，写入 `findings-additional.md`，不并入主结论。

## 7. 样本量与效力（事先承认的局限）

每体裁每条件 6 篇：足以看指涉密度与材料覆盖率（连续量、效应预计 > 2 倍），
**不足以**稳定估计 η²/ARI（依赖组内样本量）。因此 P3/P4 只作方向参考，
若与 P1 冲突，以 P1/P2 为准，并明确写"几何未能验证"。

## 8. 与既有语料的关系

既有 v2（n=57–60）在本实验中充当"薄"的历史对照；本次仍重新生成薄条件，
以排除时间漂移与接口变化。三个"薄"来源（历史 v2、本次薄）若不一致，以本次为准并报告差异。
