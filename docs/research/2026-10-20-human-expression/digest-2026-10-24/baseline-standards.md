## 二、按场景查表：哪一层真的管得着

| renhua 会遇到的情境 | 适用层 | 说明 |
|---|---|---|
| 投稿论文、图书稿件、期刊文章 | L0 + L2（15834/15835）+ L3 + CY/T 266 | 出版物，规范全部适用；编辑差错按 CY/T 266 计 |
| 学位论文 | L0 + L2 + L3 + 学校模板 | 学校规定常严于国标（如参考文献格式），以学校为准 |
| 公文、通知、公告 | L0 + GB/T 9704 + 公文处理条例 | 格式是硬要求；文风不在标准内 |
| 企业内部文档、产品说明 | L0（用字）+ L2（可参照） | 推荐性标准不强制，但违反用字规范仍属不规范 |
| 邮件、私信、社交媒体 | **基本不适用** | 只有"用规范汉字"这一层还成立；标点与数字用法属个人体例 |
| 文学创作 | L0（用字）+ 有限 L2 | 数字用法标准明确排除文艺类出版物；标点可作风格手段 |
| 口播稿、字幕 | GB/T 15834 之外另看媒体规范 | 书面标点规则不能直接搬到口语停顿 |

**这张表是"反推"能否成立的关键**：只有在表格左列「适用层」覆盖的情境里，
"不符合国家规范 ⇒ 有问题"才成立；其余情境下，规范至多提供参考。

## 三、规范能判什么、判不了什么（防止越权）

**能判（N 型）**：字形、异形词、标点形式与基本用法、数字体例、公文格式、参考文献著录（若采用相应标准）、编校差错计量。

**判不了（D/E 型）**：
- 一个句子该不该拆、该不该加连接词；
- 段落该多长、主题句该放哪；
- 用词"自然"还是"生硬"；
- 哪种表达读者更喜欢；
- "AI 味"有多重。

这些只能由实证与情境必保项来判，见[判据总表](criteria-zh.md)。

## 四、一个具体的类型化示范（省略号）

- **规范层**：GB/T 15834—2011 规定省略号的形式与用法（标示省略、话语中断等），这是 N 型，可判。
- **描述层**：即时通讯语料里，中文省略号 47.7% 用于"暗示"而非省略（COTGROVE，107 token 小库）。
- **结论**：两者**不构成冲突**。规范管的是出版物的规范用法；语料描述的是非出版场景的实际功能。
  在出版物里按规范判；在私信里按功能判；在文学里按作者体例判。这就是"条件化"处置。

凡是把这类差异写成"规范过时了"或"语料说明规范错了"，都是分型错误。

## 六、下一步：把基准变成可执行的东西

1. **取全文**：GB/T 15834 与 GB/T 15835 在国家标准全文公开系统（openstd.samr.gov.cn）可在线阅读；
   本地目前只有落地页 HTML，无法据以逐条摘录。取到全文后按条号建 `normative-rules.jsonl`。
2. **结构化**：每条规则记 `{条号, 规则, 反例, 适用域, 来源版本}`，与判据总表分开存放——
   规范规则不带"证据强度"，只有"是否现行"。
3. **做闸门**：写一个只查 N 型问题的检查脚本（标点形式、异形词、数字体例、全半角），
   作为改稿前的硬检查；它不判断风格，只判合规。
4. **版本守门**：每季度查一次 openstd 与 gov.cn，确认上述标准未被替代；标准换版时整表重核。
