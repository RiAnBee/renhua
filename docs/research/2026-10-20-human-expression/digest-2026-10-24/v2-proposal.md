# renhua v2 结构提案（2026-10-24，未实施）

> 本文件是提案，不改动 `skills/renhua/`。任何一条真要进 skill，必须先过[判据总表](criteria-zh.md)
> 的边界与[冲突清单](conflicts.md)的降级要求。

## 一、现在的问题

现行 SKILL.md 约 120 行，四类问题（空转／僵硬／衔接／手势）＋ 五组例子。它能防住"乱改"，
但有两个结构性问题：

1. **判据不可核验。** "空转""僵硬"没有触发条件，全靠模型自行领会；同一段文字，两次运行可能给出不同判断。
2. **没有情境入口。** 同一句话在邮件、公文、论文、小说里该不该改，答案相反。现在只有 5 个例子覆盖不到。

这批 678 张卡给出的，正是这两件事的材料：**情境决定必保项，必保项决定可改范围**。

## 二、v2 的骨架

```
0. 定情境     用途 / 读者 / 关系 / 媒介 → 查情境表，取"必保项"
1. 定范围     用户授权到哪一层（只改错字 / 改表达 / 可重排段落）
2. 找问题     四类问题 + 每类的触发条件（可核验，见下）
3. 改         最小改动；同一局部材料可合并，不新增事实
4. 五轴核     实体·数字·否定辖域·关系方向·承诺强度
5. 情境核     必保项逐条过一遍；有冲突就不改
6. 交稿       只给改稿；不确定的改动撤回
```

与现行版本相比，新增的是 0、4、5 三步，以及对 2 的**条件化**。

## 三、四类问题的触发条件（v2 的核心改动）

现行版本只有标签，v2 给每条加上"什么情况下成立""什么情况下撤回"。

| 问题 | 触发条件（须同时满足） | 撤回条件 | 依据 |
|---|---|---|---|
| 空转 | 连续两句不增加信息、不回应上文、不承担过渡／强调／礼貌功能；删除后段落推进不变 | 该句在回应读者疑问、限定范围、交还决定权 | a-01 Parikh（内容在话语中）；a-00 元话语总量无差异，只有句式反复可判 |
| 措辞僵硬 | 动作被名词结构遮住**且**改回动词后不影响话题与指称 | 名词化承载话题延续；被动在"讲受事者"的段落更清楚 | b-00 Gopen & Swan；ZH075 |
| 衔接妨碍 | 关系读不出来（缺）、关系已显明还加（多）、标记与关系不符（错） | 连接词承担话轮转换或让步铺垫 | b-03 MAREFAT 三类判据；RC003（分句 69.34% vs 连接词 13.21%） |
| 表达手势盖过内容 | 同一句式一篇内反复出现（框架句 70.7% 同型）；修辞本身未承载判断 | 反复承担情绪、时态或关系（陈望道"反复"）；排比不强制三项 | AUD001；ZH010；a-03 |

## 四、情境表（从判据总表压缩，进 skill 时只保留必保项与反例）

| 情境 | 一句话必保 |
|---|---|
| 学术 | 谁说的、说得多确定、术语的分类关系 |
| 技术说明 | 做什么、按什么顺序、在什么条件下 |
| 邮件／请求 | 要求多强、决定权在谁、承诺了什么 |
| 私信／网络 | 回应姿态、关系、暗示 |
| 公文／通知 | 义务、执行条件、称谓 |
| 口播／演示 | 听得清的单位、停顿、听众已知 |
| 叙事 | 谁在看、什么时候、谁在说 |
| 随笔／博客 | 作者自己的判断与态度 |

## 五、五轴保义检查（新增，替代"保义"这个词）

改完逐条核对，任何一轴变化即回退或标注：

1. **实体**：人名、地名、机构、术语是否仍在原位（反例：jeddah→islam）
2. **数字**：数量、范围、比例、时间、单位
3. **否定辖域**：否定管到哪（反例：极性改错 BLEU 76.0，正确改写 0.0）
4. **关系方向**：因果、条件、让步、先后谁指向谁（反例：词序一变意思反转）
5. **承诺强度**：hedge/booster/引述动词（"证实"≠"提到"；"可能"不能删）

## 六、明确不写进 skill

- 词表、频次、句长与标点配额
- "去 AI 味"固定动作清单（它正是 AI 润色后的特征：词数 −25%、hedge −1/3、去最高级、中性化）
- 任何自动指标作为验收依据
- "通过检测"作为目标

## 七、这批证据撑不起、必须靠评测补的部分

v2 的形态可以由现有证据支撑，但**"改完更好"没有任何中文整稿证据**。要声称提升，只能自建评测：

| 要验证的 | 最小设计 | 现有的薄弱替代 |
|---|---|---|
| 五轴保义是否可操作 | 100 对"原句／改句"，人工标五轴变化，算各轴一致率 | 现有只有英文改写数据与 κ≈0.74 的人类判断噪声 |
| 情境必保项是否够用 | 每情境 10 例真实稿件，比较"有／无情境表"的改动是否误伤 | 现有是教材与指南，非改稿结果 |
| 改动力度是否合适 | 同一稿三档力度（最小／中等／整段）由人工盲评保义、自然度、归属感 | CHI'24 的归属感数据（−3.66/−5.65）是英文、界面实验 |

评测未做之前，v2 的定位只能是"判据更清楚、边界更明确"，不能宣称"去 AI 味效果更好"。
