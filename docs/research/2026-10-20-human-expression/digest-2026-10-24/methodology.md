# 处理互斥结论的方法论（2026-10-24）

目标：让"两条证据打架"从**争论**变成**可复现的裁决**。
核心主张只有一句：**先分清争的是什么，再决定谁有权判。**

把"国家规范"当唯一基准会出错，因为绝大多数冲突根本不在规范的管辖范围内；
反过来，把实证证据抬到规范之上也会出错，因为实务里"对不对"常常由标准说了算。
所以需要的是**分型 + 分层 + 处置规则**，不是一份更长的权威清单。

---

## 一、先把冲突分型（决定后面一切）

| 型 | 争的是 | 例子 | 谁有权判 |
|---|---|---|---|
| **N 规范型** | 这么写合不合规范 | 省略号该用六连点还是三点；"其他/其它"；数字用汉字还是阿拉伯数字 | 国家/行业标准、法律法规、国家语委规范 |
| **D 描述型** | 语言事实是什么、分布如何 | AI 文本句长突发性是否更低；中文连贯问题里连接词占多少 | 实证研究（按证据分级），无"权威"可定 |
| **E 评价型** | 用什么衡量好坏、量得准不准 | BLEU 能否代表改写质量；LLM 能否当评委；人工判断一致性多少 | 方法论共识 + 预注册评测协议 |
| **I 外推型** | 这个结论能不能用到我的情境 | 英语结果能否用于中文；学习者作文能否用于成人职业写作 | 原始研究的条件（conditions），不是权威 |

**判断规则**：一句话里如果能填进"合不合规定"，是 N；能填进"实际上是不是这样"，是 D；
能填进"这个分数算不算好"，是 E；能填进"能不能推广"，是 I。

一个常见错误是把 D 当 N 判："国家标准没规定连接词密度，所以密度高低不影响质量"——这是无效推理。
反过来把 N 当 D 判也常见："语料显示省略号多表暗示，所以规范过时了"——语料描述不能废除规范，
只能说明规范管不到那个场合（即时通讯不是出版物）。

## 二、判定权分层（每层能判什么、不能判什么）

从强到弱，**只在各自管辖范围内有效**：

| 层 | 内容 | 能判 | 不能判 |
|---|---|---|---|
| L0 法律 | 《国家通用语言文字法》（2025-12-27 修订，2026-01-01 施行） | 什么场合必须用规范汉字与普通话；中文出版物须符合国家规范与标准（第十二条） | 具体标点怎么打、哪种句式更好 |
| L1 强制性国标与法规 | 《出版管理条例》《图书质量管理规定》（差错率 ≤ 万分之一为合格） | 出版物的编校质量是否合格 | 非出版场景（私信、内部文档、文学破格） |
| L2 推荐性国标／行业标准 | GB/T 15834—2011 标点符号用法；GB/T 15835—2011 出版物上数字用法；GB/T 9704—2012 党政机关公文格式；CY/T 266—2023 图书编校质量差错判定和计算方法 | 出版物与公文里的用法是否合规；差错如何计 | 推荐性标准本身不强制，除非被法规、合同或机构规定引用；不管风格 |
| L3 国务院文件与国家语委规范 | 《通用规范汉字表》（2013，8105 字）；《第一批异形词整理表》（GF 1001-2001） | 字形与异形词的规范写法 | 语法、语篇、语体 |
| L4 规范辞书与官方解读 | 《现代汉语词典》《〈标点符号用法〉解读》等 | 词形、读音、释义、标准条文的执行口径 | 语篇层面与读者效果 |
| L5 同行评议实证 | 实验、语料研究、理论 | 语言事实与读者行为（D 型）、度量是否可靠（E 型） | 规范问题（N 型）——实证不能替代标准 |
| L6 教学与实务共识 | 高校写作中心、编辑手册、教材 | 惯例、可操作做法 | 正确性；常把惯例写成规则 |
| L7 单篇观察／二手转述 | 博客、仓库、书评、综述转述 | 线索 | 一切结论 |

**关键约束**：L0–L4 **只对 N 型有效**。拿 L2 的标准去裁决"D 型"（读者加工、语体分布），是越权；
拿 L5 的实证去否定 L2 的条文，也是越权——除非能证明标准已修订、或该情境不在标准适用范围内。

## 三、实证证据分级（用于 D/E 型）

| 级 | 标准 | 权重 |
|---|---|---|
| E1 | 预注册或重复实验；中文材料；成人真实任务 | 最高 |
| E2 | 实验，但材料/被试非中文或任务非真实 | 高 |
| E3 | 大语料描述（可复现，样本量与方法透明） | 中高 |
| E4 | 小语料或单文本描述 | 中 |
| E5 | 理论推演（无数据） | 低 |
| E6 | 教学/编辑经验自述 | 低 |
| E7 | 转述他人研究、书评、综述 | 最低（不作一手证据） |

打分不是投票：**E2 的实验仍可推翻 E3 的语料描述**，因为设计能排除混淆变量。
反过来，**E3 的大样本也不能证明因果**。裁决时先看设计能否支持该结论（内部效度），再看样本量。

## 四、六步判定程序

1. **定性**：N / D / E / I（见第一节）。
2. **查域**：该规范是否覆盖这个情境？（出版物 vs 网络、公文 vs 文学、成人 vs 学习者）
3. **查时效**：是否被修订或替代？（本轮已发现：《国家通用语言文字法》2025 年修订、2026-01-01 施行；
   GB/T 15834—2011、GB/T 15835—2011 检索未见替代版本）
4. **取证**：N 型取条款号；D/E 型按 E1–E7 打分，并写出"结论成立的条件"。
5. **处置**：从第五节五种结果里选一种，写明理由。
6. **留痕**：写入裁决账本，并写出**失效条件**——什么新证据会让这条翻转。

## 五、五种处置（不许"和稀泥"）

| 处置 | 什么时候用 | 写法 |
|---|---|---|
| **采纳** | 一方明显更强（层级更高或证据等级更高，且不冲突） | 直接写成规则，带来源 |
| **条件化** | 两者在不同条件下都成立 | 写成"若〈条件〉则〈结论〉"，条件必须是可判定的 |
| **并存** | 无法条件化，但都不足以否定对方 | 两条都记，skill 中不写规则；只在注释里提示"此处有分歧" |
| **挂起（开关）** | 证据不足以下结论 | 不进入 skill 正文；登记为 open switch，等新证据 |
| **弃用** | 被更高层或更强证据否定，或本身不可操作 | 明确写"不作判据"及原因 |

**禁止**：把两条相反结论都写进 skill 让模型"自己判断"——那是把冲突转嫁给使用者，是最坏的一种处理。

## 六、原文自相矛盾的统一规则

这批材料里有 10 处同一文献内部矛盾（表与正文不符、编码与结论方向相反、摘要与数据相反）。
统一按以下顺序取信，不需要逐案讨论：

1. **可复算的数据表 > 正文叙述 > 摘要**。
2. 数据表内部不自洽（如 LL 与 p 不对应）→ **该表数值弃用，只保留方向**。
3. 变量定义与结论方向相反（如用倒数编码却说"长词更易"）→ 判 **"方向未定"**，禁引用数值与方向。
4. 作者自陈的统计量与其断言冲突（如功效 0.2 却称"足够"）→ 以统计量为准，结论降级。
5. 转述他人实验 → 一律记 E7，不得写成"该文发现"。

## 七、权威也会错：四种失效情形

你担心的"权威资料也可能不对"是对的，但不需要因此放弃基准，只需要**给权威加上失效条件**：

| 情形 | 表现 | 处理 |
|---|---|---|
| 滞后 | 标准落后于实际用法（如即时通讯里的省略号） | 承认规范不变，注明"该场合不在规范适用范围"，或等标准修订 |
| 越界 | 拿出版物规范管网络文本、拿公文格式管随笔 | 查域，退回到 D 型判断 |
| 内部冲突 | 不同层级规范打架（如行业标准与国标细节不一致） | 上位法/上位标准优先；同级按"特别规定优于一般规定" |
| 被实证限定 | 标准说"可省略"，但读者实验显示省略后有歧义 | 规范仍有效（合法），但编辑判断可加"此处不建议省略"——**合法 ≠ 合适** |

这一条是整套方法里最重要的：**规范决定"能不能"，证据决定"该不该"**。两者从不互相取消。

## 八、落到 renhua 的三条硬规则

1. **先过规范闸门**：任何改稿输出不得违反 L0–L3 的硬性规定（字形、异形词、标点用法、数字用法、公文格式）。
   这一关不需要论证，只需要查表；违反即错。
2. **再走证据闸门**：任何"更自然／更清楚／更像人"的判断必须能落到 E1–E4 的证据或情境必保项上；
   落在 E5–E7 的，只能写成建议，不能写成规则。
3. **结论一律带条件与失效条件**：没有条件的规则不允许进入 skill；有条件的写"若…则…"，并注明"什么会推翻它"。

## 九、这套方法自己不能解决的问题

- **没有中文整稿改稿实验**，所以"改完更好"永远只是推论。方法论能保证推论不越界，不能把它变成事实。
- **规范只覆盖形式合规**，覆盖不了"这段该不该删""这个比喻要不要留"。
- **E1 级证据在中文编辑领域几乎没有**，因此多数裁决会是"条件化"或"挂起"，而不是"采纳"。
  这是真实状态，不是方法失败；把它写成"采纳"才是失败。
