## 0. 一句话

> **AI 中文的可测核心是"句法扁平化 + 显性化"：句子更短、断句更频繁、连接关系更显式、嵌套修饰与虚词更少；
> 同时在语域内部的变异约为人类的 0.7 倍。语域位置基本正确，不存在"大面积越界"或"写错语域"。**

读者感到的"AI 味"，是这套扁平化在**体裁期待**下被识别，并被**标签与情境**放大的结果——
而不是某一串词或某个指标的绝对水平。

## 1. 证据（n=262，剥除代码、按标点切句、按词精确计数）

### 1.1 方向稳定的特征（两种语域同向，且效应不小）

| 特征 | 正式 r | 非正式 r | 人类正式→AI 正式 | 人类非正式→AI 非正式 |
|---|---|---|---|---|
| 平均句长 | −0.56 | −0.81 | 43.2 → **36.6** | 44.8 → **26.2** |
| 句号密度（每百字） | +0.50 | +0.73 | 1.96 → **2.33** | 1.81 → **2.91** |
| 连接词密度（每千字） | +0.56 | +0.39 | 0.83 → **2.50** | 3.17 → **4.72** |
| 的 密度（每千字） | −0.27 | −0.56 | 17.9 → **15.0** | 22.4 → **13.7** |
| 名词化后缀（每千词） | −0.11 | −0.06 | 27.3 → 22.7 | 18.0 → 15.5 |

**读法**：AI 不是"爱用某些词"，而是**把句子切短、把关系说透**。
连接词密度在正式语域是人类的三倍——这与人类正式写作（人民网）本来就用得少直接冲突，
说明它是"外来显性化"，不是"放大该语域的标记"。

### 1.2 方向不稳的特征（不能作判据）

| 特征 | 正式 r | 非正式 r | 说明 |
|---|---|---|---|
| 句长变异系数 | −0.48 | +0.13 | 正式更整齐，非正式反而更起伏 |
| 词汇类符比 | +0.54 | −0.15 | 仅正式成立 |
| 前 50 词占比 | −0.58 | +0.10 | 仅正式成立 |
| 词分布熵 | +0.50 | −0.13 | 仅正式成立 |
| 强化词 / 模糊限制语 | −0.40 / −0.16 | +0.17 / +0.25 | 双向 |
| 每段句数 | +0.40 | −0.01 | 仅正式成立，且受排版影响 |

28 个特征中 19 个方向稳定、9 个翻转；翻转集中在**词汇与立场层**。

### 1.3 分布层

| 观测 | 结果 |
|---|---|
| 语域内离散度（多变量） | AI 正式 **3.76** vs 人类 5.20；AI 非正式 **4.67** vs 人类 6.66；按 40 篇抽样仍显著更低 |
| 可分性（5 折 AUC） | **0.970 / 0.948** |
| 跨语域迁移 | 0.786 / 0.650（节奏族 0.698 / 0.525；立场 0.52 / 0.38；典型性 0.45 / 0.41） |
| 语域轴位置 | AI 正式 0.88 vs 人类 1.18（略欠正式）；AI 非正式 −1.17 vs 人类 −1.14（**基本重合**） |
| 分布外比例 | 正式 0.096、非正式 0.065（人类基线约 0.10）→ **没有大面积越界** |

## 2. 四段链条

```
生成端（受限产出 + 显性化偏好）  →  文本端（扁平化 + 变异压缩）  →  读者端（识别依赖体裁期待与线索）  →  评价/归因（受标签放大）
        推断为主                        强证据                         中等                           强证据
```

| 环节 | 判定 | 依据 |
|---|---|---|
| **生成端：受限产出** | **推断（最强候选）** | 单次生成、无受众模型、无修订、无对话史 → 预测"句短、连接显式、虚词少、名词化低"，四条方向全中。但它是**描述性框架**，不是可操纵的机制 |
| **生成端：对齐压缩多样性** | **支持（英文，检查点级）** | Kirk 2024；Sourati 2026（方差降 21–50%）；Padmakumar 2024 |
| **生成端：翻译腔** | **部分** | 显性化、简化方向命中；但代词与"的"方向与翻译腔预测相反 → 不能整体归因于翻译腔 |
| **生成端：似然/解码退化** | **降为背景** | 本地文本的词频集中与自重复都在噪声级；Holtzman 的退化形态主要见于未对齐模型 |
| **文本端：扁平化** | **强（本地）** | 句长、句号、连接词、的、名词化五条同向 |
| **文本端：变异压缩** | **强（本地）** | 0.70–0.72×，抽样稳健 |
| **读者端：加工代价** | **证据不足** | 汉语语域错配只有一项眼动（德语研究外推），效应"晚而弱"；信息结构指标上 AI 无一篇越界 |
| **读者端：识别与归因** | **强（文献）** | 无辅助识别 46.6%–55%；线索以词汇表层为主；标签显著抬高可信度与可读性 |

## 3. 竞争解释与判别

| 解释 | 预测 | 现状 |
|---|---|---|
| 语域坍塌（写成另一个语域） | AI 非正式靠近正式中心 | **否**（−1.17 vs −1.14） |
| 漫画化（各语域各自夸大） | 每格有不同的夸大轴、方向相反 | **否**：五条主效应同向；翻转集中在测量不可靠的词汇层 |
| 原型替代分布 | 只有窄，没有方向 | **部分**：窄成立，方向也成立，故"只窄"不完整 |
| 受限产出 | 短、显、平、少虚词 | **方向全中**，但不可直接操纵 |
| 纯归因（文本无差异） | 可分性接近随机 | **否**（AUC 0.97） |
| 翻译腔主导 | 代词、"的"、被动更多 | **否**（三项中两项反向） |

**最省事的组合**：**受限产出（解释方向）+ 对齐（解释窄）+ 读者线索与标签（解释"味"）**。

## 4. 最重要的反例（必须写进论文）

**专利权利要求研究（Banerjee 2026）**：法律强制"清楚简明"，人类文本落入与 LLM 默认输出相同的
低困惑度/低 burstiness 区间，三个检测器 FPR 均 >60%，换模型与领域都不变。
→ **"窄"本身不产生 AI 味**；窄只有在与体裁期待不符时才被读作机器。
这条直接限定了本文结论的适用范围：扁平化是**可测的相关物**，不是**充分原因**。

## 5. 可推翻的预测

1. 若"受限产出"成立：给模型加入修订轮次、受众信息与对话史后，五条主效应应减弱（不必改权重）。
2. 若"扁平化"是核心：把 AI 文本的句长、断句、连接词改回人类分布后，盲评"机器感"应显著下降。
3. 若"词汇层不稳"成立：任何以词汇多样性/集中度为判据的清单，应在两个语域给出相反建议。
4. 若"窄不充分"成立：在专利、法规等强制简明体裁中，人类文本与 AI 文本的"机器感"评分应无差异。

## 6. 对编辑的含义（一句话）

> 能动的是**句法**（合并短句、恢复省略与嵌套、减少不必要的显性连接），不是**词表**；
> 而且要先确认体裁期待——在强制简明的体裁里，扁平并不构成问题。
