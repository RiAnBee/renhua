# 研究方案：AI 味的发生机制（paper-shaped）

状态：执行中（2026-10-24 起，长程）
定位：不是规则清单，也不是合规审查。目标是回答**为什么**模型写出的中文会被读作"AI 味"，
以及**在这个机制下**，什么样的干预才能让 agent 产出既忠实又自然的表达。

---

## 1. 问题重述

现有做法（包括本仓库现行 skill）是"反模式清单 + 情境判断"：指出空转、僵硬、衔接、手势四类问题，
要求编辑时保护含义与语用。它有效，但**解释力不足**：说不出为什么模型会系统性地产生这些形态，
也就无法判断一条新规则是否在治因还是治症。

本研究的核心命题（待检验）：

> **"AI 味"是生成端分布偏置在特定语域中的显影：模型以"典型性"替代"适配性"，
> 造成语域错配与信息结构缺失；读者感知到的"机器感"是这种错配的加工代价与归因结果，
> 而不是一组固定表面特征的加总。**

若该命题成立，可推出一个强预测：**任何脱离语境的"形式清单"都会误伤**，
因为被判为"AI 味"的形式在不同语域里承担不同功能；这也是现有清单式做法反复失效的原因。

## 2. 四段机制链

把"AI 味"拆成四段，每段独立可测、可干预：

```
生成端偏置  →  文本端表现型  →  读者加工代价  →  归因判断（"这是 AI 写的"）
   H1–H5          M1–M5            P1–P3            A1–A2
```

### 2.1 生成端（为什么模型会这样写）

| 编号 | 机制 | 可测预测 |
|---|---|---|
| H1 | **典型性偏置**：似然最大化倾向高频、低信息量、最常见的表达 | AI 文本高频 n-gram 密度更高、词分布熵更低、罕见搭配更少；且与"正确性"无关 |
| H2 | **语域坍塌**：把"书面"默认等同"正式"，非正式语域过度正式 | 语域×来源交互：AI 在非正式语域的正式度指标显著高于人类，在正式语域差异缩小 |
| H3 | **翻译腔迁移**：训练语料含大量译入文本，习得源语结构 | AI 中文在代词显化、连接词显化、被动/"被"字句、定语前置长度上更接近译文而非原创 |
| H4 | **对齐副作用**：偏好优化奖励全面、礼貌、结构化 | 对齐后文本更长、更多框架语与总结句、hedge/booster 分布更集中 |
| H5 | **解码效应**：采样参数影响多样性但不改语域 | 温度变化改变多样性指标，不改变语域错配方向 |

### 2.2 文本端（表现型）

| 编号 | 表现型 | 操作化 |
|---|---|---|
| M1 | 语体合法性破坏 | 单双音错配、非法组配（"进行改""种植花"类）、书面度在同一段内漂移 |
| M2 | 信息结构缺失 | 主位-述题链断裂：段内话题重叠低、每句独立成立、焦点不落 |
| M3 | 指称与衔接失配 | 代词先行项不可唯一确定；连接词与真实关系不符（多余/缺失/误用三类） |
| M4 | 立场与承诺均质 | hedge/booster/引述动词种类少、强度集中于中间档 |
| M5 | 节奏与排版均质 | 句长集中、段落句数整齐、标点种类少（**弱证据**：随机文本也可产生长程相关） |

### 2.3 加工端（读者为什么觉得累/假）

- P1 指称解析失败带来额外加工（Clark & Haviland 类）。
- P2 语域期待违反带来"别扭"而非"难读"（两者是不同指标：SUP004 的加工便利 vs 自然度分离）。
- P3 关系重算（连接词与真实关系不符）比缺少连接词代价更高。

### 2.4 归因端

- A1 "AI 味"是归因判断，不是文本固有属性：同文在不同情境、不同读者下判断不同。
- A2 质量判断与来源判断分离：保分好不等于不被识破（06772：句级改写保分最好却被识破 0.74）。

## 3. 方法

### 3.1 证据合成（已有）

678 张卡（295 篇）已覆盖 M1–M5 与 P1–P3 的大部分经验证据，见
[判据总表](../digest-2026-10-24/criteria-zh.md) 与 [裁决账本](../digest-2026-10-24/decision-ledger.md)。

### 3.2 缺口检索（针对 H1–H5）

H1–H5 是**生成端**机制，现有语料库覆盖薄弱（多为检测与改写，少有"为什么"。本轮定向检索：
典型性/模式坍塌、RLHF 风格漂移、解码与多样性、翻译腔迁移、语域理论、信息结构、人类归因实验。

### 3.3 本地观测（2×2 语料设计）

`corpus/` 下四格：人类正式 101、人类非正式 83、AI 正式 41、AI 非正式 41。
按 $\text{来源} \times \text{语域}$ 提取表现型指标，检验：

- **P1（语域主效应）**：语域解释的方差大于来源；
- **P2（交互）**：区分 AI 的特征在正式与非正式语域不同向或不显著（即"清单失效"的可测形式）；
- **P3（表现型 vs 加工代理）**：以指称距离、话题重叠、关系标记一致性作为加工代理，检验其与"来源"的关联强于表面特征。

局限（必须写进论文）：非配对、AI 文本为合成、样本小（n=266 篇）、无人类读者判断。
因此本地部分只作**机制的存在性检验**，不作效果声明。

### 3.4 干预推导（反推落地）

从机制推出三类干预，并给出可检验预测：

1. **语域锚定**：先定语域再定形式（对应 H2）。
2. **信息结构重建**：以主位-述题链为单位编辑，而非句为单位（对应 M2/P1）。
3. **保义与承诺分层**：内容、立场、声音三层分别核（对应 M4/A2）。

## 4. 停止条件（什么时候算"解决"）

满足以下三条即停，不追加：

1. 四段机制链每段至少有一条可核验证据，且 H1–H5 各有支持/反驳/无证据的明确判定；
2. 本地观测给出 P1–P3 的数值结果（含效应量与样本量），并写明不能推出的部分；
3. 从机制推出可实施的干预规格（不是规则清单），且标明其可被什么实验推翻。
